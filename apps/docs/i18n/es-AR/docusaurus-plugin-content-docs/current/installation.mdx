Instalá el paquete desde una versión de GitHub con la herramienta `pkg` de pfSense y después confirmá que sus páginas aparecen en la WebGUI.

## Requisitos \{#requirements}

- **Shell de administrador** — Acceso por SSH o por consola a la shell de pfSense. **Diagnostics → Command Prompt** en la WebGUI también permite ejecutar comandos sueltos.
- **Acceso HTTPS a GitHub** — El firewall descarga el paquete desde GitHub Releases.
- **Una versión de pfSense compatible** — Usá pfSense CE 2.9.1, 2.9.0 o 2.8.1, o bien pfSense Plus 26.07.1, 26.07 o 26.03.1. La pestaña **Acerca de** muestra las versiones de pfSense en las que se probó cada versión del paquete.
- **Una copia de seguridad reciente** — Descargá una copia de la configuración desde **Diagnostics → Backup & Restore** antes de instalar.
- **El <Terminology title="Versión 1.x: el script update.php ejecutado por el paquete Cron" to="/docs/reference/terminology#package-origins">actualizador heredado</Terminology> puede quedarse** — Si el script de la versión 1.x todavía se ejecuta desde el paquete Cron, dejalo como está. El paso de instalación lo traslada al paquete, como explica [Migrar desde el script](/docs/migrate-from-legacy).

:::warning

IPv6 Prefix Updater for pfSense es un <Terminology title="Instalado desde GitHub, no desde el repositorio de paquetes de Netgate" to="/docs/reference/terminology#package-origins">paquete no oficial</Terminology>. Instalar un archivo `.pkg` desde GitHub saltea la revisión y el soporte de paquetes de Netgate, por lo que se recomienda probarlo primero en un firewall con copia de seguridad o descartable.

:::

## Verificar la versión \{#check-the-release}

Las versiones del paquete aparecen en la [página GitHub Releases](https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases). Cada versión del paquete incluye estos archivos:

| Archivo                                       | Descripción                                                                    |
|-----------------------------------------------|--------------------------------------------------------------------------------|
| `pfSense-pkg-Ipv6PrefixUpdater.pkg`           | El paquete con un nombre fijo, que es el que usan los comandos de esta página. |
| `pfSense-pkg-Ipv6PrefixUpdater-<version>.pkg` | El mismo paquete con su versión en el nombre del archivo.                      |
| Archivos `.sha256`                            | Una suma de verificación SHA-256 para cada archivo del paquete.                |

:::info

Las versiones 1.x solo contienen el <Terminology title="Versión 1.x: el script update.php ejecutado por el paquete Cron" to="/docs/reference/terminology#package-origins">actualizador heredado</Terminology>. Si la última versión no tiene ningún archivo `.pkg`, los comandos de esta página fallan con un error de no encontrado (404).

:::

## Instalar el paquete \{#install-the-package}

Ejecutá este mismo comando desde la shell de pfSense para una primera instalación, una actualización o una reinstalación:

```shell
pkg add -f https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg
```

`pkg` descarga el paquete de la última versión y ejecuta su paso de instalación, que registra **Services → IPv6 Prefix Updater** en pfSense. La opción `-f` permite que el mismo comando instale el paquete, actualice una versión anterior o reinstale la versión actual. Sin ella, pfSense CE 2.8 informa que una actualización ya está instalada y no cambia la versión instalada.

## Verificar primero la descarga \{#verify-the-download-first}

Para verificar el archivo con su suma de verificación antes de instalarlo, descargá los dos archivos en `/tmp` y mostrá ambos valores:

```shell
cd /tmp
fetch https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg
fetch https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg.sha256
sha256 -q pfSense-pkg-Ipv6PrefixUpdater.pkg
cat pfSense-pkg-Ipv6PrefixUpdater.pkg.sha256
```

Los dos últimos comandos muestran el mismo valor cuando la descarga está intacta. Después podés instalar el archivo verificado con `pkg add -f /tmp/pfSense-pkg-Ipv6PrefixUpdater.pkg`.

## Confirmar en la WebGUI \{#confirm-in-the-webgui}

1. Iniciá sesión en la WebGUI de pfSense.
2. Abrí **Services → IPv6 Prefix Updater** y confirmá que aparecen las pestañas **Configuración**, **Estado**, **Campos**, **Copias de seguridad**, **Limpieza** y **Acerca de**.
3. En la pestaña Estado, confirmá que **Estado actual** muestra `Todavía no hay interfaces supervisadas guardadas. Agregalas en la pestaña Configuración.` Después de la migración del actualizador heredado, muestra en cambio las interfaces trasladadas.
4. Dejá **<Terminology title="Comprobaciones automáticas programadas, apagadas por defecto" to="/docs/reference/terminology#running-checks">Activar actualizaciones programadas</Terminology>** destildada, como viene por defecto, hasta que [establezcas la referencia](/docs/first-run). Después de la migración del actualizador heredado, ya está activada, según la programación de Cron anterior.

## Si la instalación falla \{#if-installation-fails}

- **No encontrado (404)**: la última versión no tiene ningún archivo de paquete. [Verificar la versión](/docs/installation#check-the-release) explica qué versiones incluyen uno.
- **Arquitectura incorrecta en pfSense CE 2.9.0**: las versiones hasta la 2.0.1 inclusive se compilaron solo para FreeBSD 15, por lo que pfSense CE 2.9.0 muestra un mensaje de arquitectura incorrecta para ellas. Instalá la versión más reciente.
- **Errores de DNS, TLS o certificados**: pfSense necesita resolver `github.com`, conectarse por HTTPS y tener la hora correcta para validar los certificados.

Seguí con [Establecer la referencia](/docs/first-run) cuando el paquete aparezca en la WebGUI.
