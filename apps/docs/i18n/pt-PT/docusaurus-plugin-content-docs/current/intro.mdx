Mantenha os endereços IPv6 guardados no pfSense no prefixo atual quando o ISP atribui um novo <Terminology title="A rede IPv6 que o seu fornecedor lhe atribui, e que pode mudar" to="/docs/reference/terminology#addresses-and-prefixes">prefixo delegado</Terminology>.

## O que faz \{#what-it-does}

O IPv6 Prefix Updater for pfSense é um pacote do pfSense que monitoriza as interfaces que escolher para detetar um novo prefixo. Quando o prefixo muda, reescreve os endereços correspondentes nos campos que selecionar e mantém a <Terminology title="Os bits depois do prefixo, sempre copiados sem alteração" to="/docs/reference/terminology#addresses-and-prefixes">parte de anfitrião</Terminology> de cada um.

## Porquê usar este pacote? \{#why-use-this-package}

1. Mantém a <Terminology title="Os bits depois do prefixo, sempre copiados sem alteração" to="/docs/reference/terminology#addresses-and-prefixes">parte de anfitrião</Terminology> de cada endereço, para que cada dispositivo conserve o mesmo sufixo após uma mudança de prefixo.
2. Altera apenas os <Terminology title="Uma configuração que o pacote pode reescrever" to="/docs/reference/terminology#fields-and-change-plans">campos aprovados</Terminology> que selecionar no separador Campos, para que as redes VPN remotas, os pares, os gateways e as rotas fiquem como os definiu.
3. Guarda uma <Terminology title="Uma cópia da configuração feita mesmo antes de qualquer gravação" to="/docs/reference/terminology#backups-and-service-reloads">cópia de segurança da configuração</Terminology> antes de cada gravação, para que a configuração anterior fique disponível no <Terminology title="As revisões de configuração guardadas pelo pfSense para restaurar" to="/docs/reference/terminology#backups-and-service-reloads">Config History</Terminology>.
4. Funciona com um agendamento gerido pelo pfSense, pelo que dispensa o pacote Cron e qualquer script numa pasta pessoal.
5. Mostra cada resultado no separador Estado, para que veja o que mudou, que serviços foram recarregados e se foi criada uma cópia de segurança.

## O que atualiza \{#what-it-updates}

- **Aliases**: endereços e redes em aliases dos tipos Host e Network.
- **Interfaces estáticas**: endereços de interfaces configuradas como Static IPv6.
- **<Terminology title="Um endereço extra numa interface, como um VIP CARP" to="/docs/reference/terminology#pfsense-features">Endereços IP virtuais</Terminology>**: <Terminology title="Um endereço extra numa interface, como um VIP CARP" to="/docs/reference/terminology#pfsense-features">IPs virtuais</Terminology> CARP e IP Alias.
- **IPsec**: o lado local das entradas de <Terminology title="A entrada IPsec que define as redes local e remota de um túnel" to="/docs/reference/terminology#pfsense-features">fase 2</Terminology> Tunnel IPv6 e Routed (VTI).
- **OpenVPN**: redes de túnel e redes locais IPv6 em servidores e em <Terminology title="Configurações do OpenVPN que valem para um único cliente" to="/docs/reference/terminology#pfsense-features">substituições específicas de cliente</Terminology>, e redes de túnel IPv6 em clientes.
- **WireGuard**: <Terminology title="O endereço de uma interface de túnel WireGuard" to="/docs/reference/terminology#pfsense-features">endereços de túnel</Terminology>, quando o pacote WireGuard está instalado.
- **Servidor DHCPv6**: intervalos de endereços, de delegação de prefixos e de pools, mapeamentos estáticos e os servidores DNS e NTP entregues aos clientes.
- **Anúncios de router**: servidores DNS anunciados e sub-redes RA.
- **Substituições de anfitriões DNS**: substituições de anfitriões no DNS Resolver e no DNS Forwarder.
- **Regras da firewall**: endereços de origem e de destino escritos nas regras.
- **NAT e NPt**: endereços escritos em reencaminhamentos de portas, NAT de saída e NAT 1:1, e prefixos NPt.
- **Definições de outros pacotes**: apenas os campos que marcar, e depois o pacote aplica novamente as definições desse pacote.

O separador **Campos** lista todos os endereços contidos no seu prefixo, com um interruptor para cada <Terminology title="Um único botão para um tipo inteiro de configuração" to="/docs/reference/terminology#fields-and-change-plans">grupo de campos</Terminology> e uma caixa de verificação para cada campo.

## O que fica à sua espera \{#what-waits-for-you}

O grupo **Outras definições** começa desativado, pelo que estes valores só mudam quando os marcar:

- O lado remoto de uma VPN, como as redes remotas IPsec e OpenVPN e os pares, IPs permitidos e pontos finais do WireGuard.
- Gateways, rotas estáticas, substituições de domínio DNS, certificados, segredos, valores codificados em Base64 e descrições.
- Aliases dos tipos Port, URL e outros.

As interfaces que obtêm o endereço por DHCPv6, SLAAC ou <Terminology title="Uma interface que forma o IPv6 a partir do prefixo de outra" to="/docs/reference/terminology#interfaces-and-detection">Track Interface</Terminology> nunca são alteradas, porque é o pfSense que gera esses endereços. O mesmo se aplica aos endereços IPv4, aos nomes de anfitrião e aos endereços IPv6 fora do prefixo antigo. A lista completa está em [Outras definições](/docs/configure/configuration-scopes#other-settings).

## Como funciona uma verificação \{#how-a-check-works}

1. Lê o <Terminology title="Um endereço IPv6 público em 2000::/3, o único tipo usado" to="/docs/reference/terminology#addresses-and-prefixes">endereço global</Terminology> de cada <Terminology title="A interface cujo endereço revela o seu prefixo atual" to="/docs/reference/terminology#interfaces-and-detection">Interface monitorizada</Terminology> e calcula o respetivo prefixo.
2. Compara-o com o <Terminology title="O prefixo guardado com o qual cada verificação compara" to="/docs/reference/terminology#baselines-and-transitions">último prefixo bem-sucedido</Terminology> e termina com <Terminology title="O mesmo prefixo da última vez, por isso não há nada a fazer" to="/docs/reference/terminology#run-outcomes">Sem alteração</Terminology> se coincidirem.
3. Perante uma <Terminology title="O seu prefixo mudou, por isso o pacote entra em ação" to="/docs/reference/terminology#baselines-and-transitions">transição de prefixo</Terminology>, cria um <Terminology title="Cada reescrita prevista, preparada antes de qualquer mudança" to="/docs/reference/terminology#fields-and-change-plans">plano de alterações</Terminology> para os <Terminology title="Uma configuração que o pacote pode reescrever" to="/docs/reference/terminology#fields-and-change-plans">campos aprovados</Terminology> que ainda usam o prefixo antigo.
4. Guarda uma <Terminology title="Uma cópia da configuração feita mesmo antes de qualquer gravação" to="/docs/reference/terminology#backups-and-service-reloads">cópia de segurança da configuração</Terminology>, grava todas as alterações de uma só vez, recarrega apenas os serviços afetados e volta a verificar os valores.
5. Regista o resultado no separador Estado e envia uma <Terminology title="O alerta enviado depois de os seus endereços serem atualizados" to="/docs/reference/terminology#notifications-and-logs">notificação de alteração</Terminology>, se estiver ativada.

O [Modelo de segurança](/docs/operations) descreve as proteções de cada passo.

## Antes de começar \{#before-you-start}

:::warning

O IPv6 Prefix Updater for pfSense é um <Terminology title="Instalado pelo GitHub, não pelo repositório de pacotes da Netgate" to="/docs/reference/terminology#package-origins">pacote não oficial</Terminology>. É instalado a partir do GitHub com o `pkg`, e a Netgate não o revê nem lhe presta suporte.

:::

As versões do pacote são publicadas na página GitHub Releases do projeto. As versões 1.x contêm apenas o <Terminology title="Versão 1.x: o script update.php executado pelo pacote Cron" to="/docs/reference/terminology#package-origins">atualizador legado</Terminology>, e não este pacote.

## Idiomas \{#languages}

Todos os separadores do pacote, a <Terminology title="As linhas da última execução, mostradas logo após o início" to="/docs/reference/terminology#running-checks">Saída do comando</Terminology> e as mensagens do pacote seguem o idioma selecionado no pfSense. O pacote inclui traduções para 18 opções de idioma do pfSense e recorre ao inglês para qualquer outro idioma.
