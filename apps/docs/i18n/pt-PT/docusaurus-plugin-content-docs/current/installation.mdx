Instale o pacote a partir de uma versão publicada no GitHub com a ferramenta `pkg` do pfSense e confirme depois que as respetivas páginas aparecem na WebGUI.

## Requisitos \{#requirements}

- **Shell de administrador** — Acesso SSH ou por consola à shell do pfSense. A opção **Diagnostics → Command Prompt** da WebGUI também permite executar comandos isolados.
- **Acesso HTTPS ao GitHub** — A firewall transfere o pacote a partir das GitHub Releases.
- **Uma compilação compatível do pacote** — O pacote tem de ser compilado para a versão do FreeBSD usada pela sua versão do pfSense.
- **Uma cópia de segurança recente** — Transfira uma cópia da configuração em **Diagnostics → Backup & Restore** antes de instalar.
- **O <Terminology title="script update.php original executado pelo pacote Cron" to="/docs/reference/terminology#legacy-updater">atualizador legado</Terminology> pode ficar** — Se o script da versão 1.x ainda for executado pelo pacote Cron, deixe-o onde está. O passo de instalação move-o para o pacote, como explica [Migrar a partir do script](/docs/migrate-from-legacy).

:::warning

O pfSense IPv6 Prefix Updater é um <Terminology title="pacote instalado do GitHub, não do repositório da Netgate" to="/docs/reference/terminology#unofficial-package">pacote não oficial</Terminology>. Instalar um ficheiro `.pkg` a partir do GitHub contorna a revisão e o suporte de pacotes da Netgate, pelo que se recomenda experimentá-lo primeiro numa firewall com cópia de segurança ou descartável.

:::

## Verificar a versão \{#check-the-release}

As versões do pacote estão listadas na [página GitHub Releases](https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases). Cada versão do pacote inclui estes ficheiros:

| Ficheiro                                      | Descrição                                                     |
|-----------------------------------------------|---------------------------------------------------------------|
| `pfSense-pkg-Ipv6PrefixUpdater.pkg`           | O pacote com um nome fixo, usado pelos comandos desta página. |
| `pfSense-pkg-Ipv6PrefixUpdater-<version>.pkg` | O mesmo pacote com a versão no nome do ficheiro.              |
| Ficheiros `.sha256`                           | Uma soma de verificação SHA-256 para cada ficheiro do pacote. |

:::info

As versões 1.x contêm apenas o <Terminology title="script update.php original executado pelo pacote Cron" to="/docs/reference/terminology#legacy-updater">atualizador legado</Terminology>. Se a versão mais recente não tiver um ficheiro `.pkg`, os comandos desta página falham com um erro de não encontrado (404).

:::

## Instalar o pacote \{#install-the-package}

Execute este comando na shell do pfSense:

```shell
pkg add -f https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg
```

O `pkg` transfere o pacote da versão mais recente e executa o respetivo passo de instalação, que regista **Services → IPv6 Prefix Updater** no pfSense.

## Verificar primeiro a transferência \{#verify-the-download-first}

Para comparar o ficheiro com a respetiva soma de verificação antes de instalar, transfira os dois ficheiros para `/tmp` e mostre os dois valores:

```shell
cd /tmp
fetch https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg
fetch https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg.sha256
sha256 -q pfSense-pkg-Ipv6PrefixUpdater.pkg
cat pfSense-pkg-Ipv6PrefixUpdater.pkg.sha256
```

Os dois últimos comandos mostram o mesmo valor quando a transferência está íntegra. Pode depois instalar o ficheiro verificado com `pkg add -f /tmp/pfSense-pkg-Ipv6PrefixUpdater.pkg`.

## Confirmar na WebGUI \{#confirm-in-the-webgui}

1. Inicie sessão na WebGUI do pfSense.
2. Abra **Services → IPv6 Prefix Updater** e confirme que aparecem os separadores **Definições**, **Estado**, **Campos**, **Cópias de segurança** e **Limpeza**.
3. No separador Estado, confirme que **Estado atual** mostra `Ainda não há interfaces monitorizadas guardadas. Adicione-as no separador Definições.` Após a migração do atualizador legado, mostra as interfaces migradas em vez dessa mensagem.
4. Deixe a opção **<Terminology title="verificações automáticas por entrada cron gerida pelo pfSense" to="/docs/reference/terminology#scheduled-updates">Ativar atualizações agendadas</Terminology>** desmarcada, como vem por predefinição, até [estabelecer a referência](/docs/first-run). Após a migração do atualizador legado, já está marcada, de acordo com o antigo agendamento do Cron.

## Se a instalação falhar \{#if-installation-fails}

- **Não encontrado (404)**: a versão mais recente não tem ficheiro de pacote. A secção [Verificar a versão](/docs/installation#check-the-release) explica que versões incluem um.
- **Incompatibilidade de ABI ou de versão do SO**: o pacote foi compilado para uma versão do FreeBSD diferente da usada pela sua versão do pfSense. Recomenda-se usar uma compilação compatível em vez de forçar a instalação.
- **Erros de DNS, TLS ou de certificado**: o pfSense tem de resolver `github.com`, contactá-lo por HTTPS e manter a hora certa para a verificação de certificados.

Continue com [Estabelecer a referência](/docs/first-run) assim que o pacote aparecer na WebGUI.
