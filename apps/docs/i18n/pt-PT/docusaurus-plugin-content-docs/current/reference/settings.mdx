Consulte cada campo do separador Definições com o respetivo valor predefinido e os valores que aceita.

## Monitorização do prefixo \{#prefix-monitoring}

O separador **Definições** em **Services → IPv6 Prefix Updater** começa com estes campos, e guardar o formulário mostra `Definições guardadas.`

| Campo                                                                                                                                                                                        | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="Verificações automáticas agendadas, desligadas até as ativar" to="/docs/reference/terminology#running-checks">Ativar atualizações agendadas</Terminology>                | Executa verificações segundo a **Agenda** selecionada. Desmarcada por predefinição, e guardar adiciona ou remove a entrada cron.                                                                                                                                                                                                                                                                                                                                                      |
| <Terminology title="A interface cujo endereço revela o seu prefixo atual" to="/docs/reference/terminology#interfaces-and-detection">Interfaces monitorizadas</Terminology>                   | Obrigatório. Uma linha por cada interface cujo <Terminology title="Um endereço IPv6 público em 2000::/3, o único tipo usado" to="/docs/reference/terminology#addresses-and-prefixes">endereço global</Terminology> contém um <Terminology title="A rede IPv6 que o seu fornecedor lhe atribui, e que pode mudar" to="/docs/reference/terminology#addresses-and-prefixes">prefixo delegado</Terminology>. **Adicionar** adiciona uma linha, e cada interface só pode aparecer uma vez. |
| <Terminology title="O tamanho do prefixo do seu fornecedor, como /56; definido por si" to="/docs/reference/terminology#addresses-and-prefixes">Comprimento do prefixo delegado</Terminology> | Obrigatório em cada linha. De `/48` a `/64`, com `/56` selecionado por predefinição.                                                                                                                                                                                                                                                                                                                                                                                                  |
| Agenda                                                                                                                                                                                       | A cada 15 minutos, De hora a hora, A cada 6 horas ou Diariamente à meia-noite. De hora a hora por predefinição.                                                                                                                                                                                                                                                                                                                                                                       |

## Seleção de campos \{#field-selection}

Abaixo do campo **Agenda**, o separador Definições mostra `Escolha no separador Campos que campos da configuração mudam com o prefixo.` Os <Terminology title="Um único botão para um tipo inteiro de configuração" to="/docs/reference/terminology#fields-and-change-plans">grupos de campos</Terminology> e os campos individuais são escolhidos no separador **Campos** e guardados à parte destas definições, pelo que guardar o separador Definições nunca os altera. A página [Campos](/docs/configure/configuration-scopes) descreve cada grupo e a respetiva predefinição.

## Notificações \{#notifications}

| Campo                                                                                                                                                                                      | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="O alerta enviado depois de os seus endereços serem atualizados" to="/docs/reference/terminology#notifications-and-logs">Enviar notificações de alteração</Terminology> | Selecionado por predefinição. Envia uma <Terminology title="O alerta enviado depois de os seus endereços serem atualizados" to="/docs/reference/terminology#notifications-and-logs">notificação de alteração</Terminology> após cada <Terminology title="O prefixo mudou e cada campo aprovado foi atualizado" to="/docs/reference/terminology#run-outcomes">Sucesso</Terminology>, enquanto os alertas de <Terminology title="O prefixo mudou, mas nenhum campo aprovado usava o antigo" to="/docs/reference/terminology#run-outcomes">Aviso</Terminology> e de <Terminology title="A execução parou em uma verificação ou etapa de segurança" to="/docs/reference/terminology#run-outcomes">Falha</Terminology> aparecem em qualquer caso. |

## Atualizações do pacote \{#package-updates}

| Campo | Descrição |
|-|-|
| Verificações de atualizações | Diariamente, Semanalmente, Mensalmente ou Nunca. Semanalmente por predefinição. A verificação é executada a uma hora aleatória mas estável. [Atualizações](/docs/reference/updates) descreve o que faz. |
| Notificações remotas | Desligada por predefinição. Envia também cada aviso de nova versão através dos canais de notificação remotos configurados no pfSense, como e-mail, Telegram ou Pushover. |

## Mensagens de validação \{#validation-messages}

| Mensagem                                                                                          | Causa                                                                                             |
|---------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------|
| `Selecione uma interface pfSense configurada para monitorizar.`                                   | Não existe nenhuma linha, ou a interface de uma linha não é uma interface do pfSense configurada. |
| `Cada interface só pode constar uma vez. Remova a linha a mais de <interface>.`                   | Duas linhas de **Interfaces monitorizadas** indicam a mesma interface.                            |
| `O comprimento do prefixo delegado deve estar entre 48 e 64.`                                     | O comprimento está fora do intervalo aceite.                                                      |
| `Selecione uma agenda de pacote suportada.`                                                       | A agenda não é uma das quatro opções.                                                             |
| `Selecione Diariamente, Semanalmente, Mensalmente ou Nunca para as verificações de atualizações.` | **Verificações de atualizações** não é uma das quatro opções.                                     |

Cada execução volta a verificar as definições guardadas, porque podem ter mudado depois de o formulário ter sido guardado. A secção [Resolução de problemas](/docs/operate/troubleshooting#run-failed) lista as mensagens que uma execução pode indicar.
