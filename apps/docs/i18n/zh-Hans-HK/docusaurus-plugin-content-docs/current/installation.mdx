使用 pfSense 的 `pkg` 工具从 GitHub 发布版本安装软件包，然后确认其页面已出现在 WebGUI 中。

## 前提条件 \{#requirements}

- **管理员 shell** — 通过 SSH 或控制台访问 pfSense shell。也可以在 WebGUI 的 **Diagnostics → Command Prompt**（诊断 → 命令提示符）中运行单条命令。
- **可通过 HTTPS 访问 GitHub** — 防火墙会从 GitHub Releases 下载软件包。
- **受支持的 pfSense 版本** — 使用 pfSense CE 2.9.1、2.9.0 或 2.8.1，或 pfSense Plus 26.07.1、26.07 或 26.03.1。**关于** 选项卡会列出每个软件包版本经过测试的 pfSense 版本。
- **最新备份** — 安装前，在 **Diagnostics → Backup & Restore**（诊断 → 备份与恢复）中下载一份配置副本。
- **<Terminology title="1.x 版本：由 Cron 软件包运行的 update.php 脚本" to="/docs/reference/terminology#package-origins">旧版更新器</Terminology>可以保留** — 如果 1.x 版脚本仍在通过 Cron 软件包运行，请保持原样。安装步骤会将其迁移到软件包中，如[从脚本迁移](/docs/migrate-from-legacy)所述。

:::warning

IPv6 Prefix Updater for pfSense 是<Terminology title="从 GitHub 安装，而非来自 Netgate 软件包仓库" to="/docs/reference/terminology#package-origins">非官方软件包</Terminology>。从 GitHub 安装 `.pkg` 文件会绕过 Netgate 的软件包审核和支持，因此建议先在已备份或可随时重建的防火墙上试用。

:::

## 检查发布版本 \{#check-the-release}

软件包版本列在 [GitHub Releases 页面](https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases)上。每个软件包版本都包含以下文件：

| 文件                                            | 说明                        |
|-----------------------------------------------|---------------------------|
| `pfSense-pkg-Ipv6PrefixUpdater.pkg`           | 使用固定文件名的软件包，本页的命令使用此文件。   |
| `pfSense-pkg-Ipv6PrefixUpdater-<version>.pkg` | 同一软件包，文件名中带有版本号。          |
| `.sha256` 文件                                  | 每个软件包文件各对应一个 SHA-256 校验和。 |

:::info

1.x 版本只包含<Terminology title="1.x 版本：由 Cron 软件包运行的 update.php 脚本" to="/docs/reference/terminology#package-origins">旧版更新器</Terminology>。如果最新发布版本中没有 `.pkg` 文件，本页的命令会因找不到文件（404）而失败。

:::

## 安装软件包 \{#install-the-package}

首次安装、更新或重新安装时，都可在 pfSense shell 中运行以下同一条命令：

```shell
pkg add -f https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg
```

`pkg` 会从最新发布版本下载软件包并运行其安装步骤，在 pfSense 中注册 **Services → IPv6 Prefix Updater**（服务 → IPv6 Prefix Updater）。`-f` 选项使同一条命令可以安装软件包、更新旧版本或重新安装当前版本。如果不加该选项，pfSense CE 2.8 会将更新报告为已安装，并保持当前安装版本不变。

## 先校验下载文件 \{#verify-the-download-first}

如果想在安装前用校验和核对文件，请将两个文件都下载到 `/tmp`，然后输出这两个值：

```shell
cd /tmp
fetch https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg
fetch https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg.sha256
sha256 -q pfSense-pkg-Ipv6PrefixUpdater.pkg
cat pfSense-pkg-Ipv6PrefixUpdater.pkg.sha256
```

下载完整无损时，最后两条命令会输出相同的值。之后即可用 `pkg add -f /tmp/pfSense-pkg-Ipv6PrefixUpdater.pkg` 安装已校验的文件。

## 在 WebGUI 中确认 \{#confirm-in-the-webgui}

1. 登录 pfSense WebGUI。
2. 打开 **Services → IPv6 Prefix Updater**，确认出现 **设置**、**状态**、**字段**、**备份**、**清理** 和 **关于** 选项卡。
3. 在“状态”选项卡中，确认 **当前状态** 显示 `尚未保存任何监控接口。请在“设置”选项卡上添加。` 从旧版更新器迁移后，这里会改为列出迁移过来的接口。
4. 在[建立基线](/docs/first-run)之前，让 **<Terminology title="按计划自动检查，启用前一直关闭" to="/docs/reference/terminology#running-checks">启用计划更新</Terminology>** 保持默认的未勾选状态。从旧版更新器迁移后，该选项已按旧的 Cron 计划开启。

## 安装失败时 \{#if-installation-fails}

- **找不到文件（404）**：最新发布版本中没有软件包文件。[检查发布版本](/docs/installation#check-the-release)说明了哪些版本包含软件包文件。
- **pfSense CE 2.9.0 上的架构错误**：截至 2.0.1 的发布版本仅针对 FreeBSD 15 构建，因此 pfSense CE 2.9.0 会为这些版本显示错误架构消息。请安装最新发布版本。
- **DNS、TLS 或证书错误**：pfSense 需要能够解析 `github.com`、通过 HTTPS 访问它，并保持正确的时间以便检查证书。

软件包出现在 WebGUI 中后，请继续阅读[建立基线](/docs/first-run)。
