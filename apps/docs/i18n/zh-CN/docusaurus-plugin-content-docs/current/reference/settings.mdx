查阅“设置”选项卡上的每个字段及其默认值和可接受的值。

## 前缀监控 \{#prefix-monitoring}

**Services → IPv6 Prefix Updater** 下的 **设置** 选项卡以这些字段开头，保存表单后会显示 `设置已保存。`

| 字段                                                                                                                      | 说明                                                                                                                                                                                                                                                                                             |
|-------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="按计划自动检查，启用前一直关闭" to="/docs/reference/terminology#running-checks">启用计划更新</Terminology>               | 按所选的 **计划** 运行检查。默认关闭，保存时会添加或删除 cron 条目。                                                                                                                                                                                                                                                       |
| <Terminology title="通过其地址揭示当前前缀的接口" to="/docs/reference/terminology#interfaces-and-detection">监控接口</Terminology>        | 必填。每个<Terminology title="位于 2000::/3 内的公网 IPv6 地址，唯一会用到的类型" to="/docs/reference/terminology#addresses-and-prefixes">全局地址</Terminology>承载<Terminology title="ISP 分配给你的 IPv6 网络，可能会变化" to="/docs/reference/terminology#addresses-and-prefixes">委派前缀</Terminology>的接口占一行。**添加** 会添加一行，每个接口只能出现一次。 |
| <Terminology title="ISP 前缀的大小，例如 /56，由你设置" to="/docs/reference/terminology#addresses-and-prefixes">委派前缀长度</Terminology> | 每行必填。范围为 `/48` 到 `/64`，默认选择 `/56`。                                                                                                                                                                                                                                                             |
| 计划                                                                                                                      | 每 15 分钟、每小时、每 6 小时或每天午夜。默认为每小时。                                                                                                                                                                                                                                                                |

## 字段选择 \{#field-selection}

在 **计划** 下方，“设置”选项卡会显示 `在“字段”选项卡中选择哪些配置字段随前缀变化。` <Terminology title="一个开关管住一整类设置" to="/docs/reference/terminology#fields-and-change-plans">字段组</Terminology>和单个字段在 **字段** 选项卡中选择，并与这些设置分开保存，因此保存“设置”选项卡绝不会更改它们。[字段](/docs/configure/configuration-scopes)介绍了每个组及其默认状态。

| 字段                                                                                                           | 说明                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|--------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="地址更新后发送的通知" to="/docs/reference/terminology#notifications-and-logs">发送变化通知</Terminology> | 默认勾选。每次<Terminology title="前缀变了，所有已批准字段都已更新" to="/docs/reference/terminology#run-outcomes">成功</Terminology>后发送<Terminology title="地址更新后发送的通知" to="/docs/reference/terminology#notifications-and-logs">变化通知</Terminology>；无论是否勾选，<Terminology title="前缀变了，但没有已批准字段使用旧前缀" to="/docs/reference/terminology#run-outcomes">警告</Terminology>和<Terminology title="运行在某个检查或安全阶段停止" to="/docs/reference/terminology#run-outcomes">失败</Terminology>通知都会出现。 |

## 软件包更新 \{#package-updates}

| 字段 | 说明 |
|-|-|
| 更新检查 | 每天、每周、每月或从不。默认为每周。检查会在一个固定的随机时间运行。[更新](/docs/reference/updates)介绍了它的作用。 |
| 远程通知 | 默认关闭。同时通过 pfSense 中已配置的远程通知渠道（例如电子邮件、Telegram 或 Pushover）发送每条新版本通知。 |

## 验证消息 \{#validation-messages}

| 消息                                 | 原因                              |
|------------------------------------|---------------------------------|
| `请选择要监控的已配置 pfSense 接口。`           | 没有任何行，或某一行的接口不是已配置的 pfSense 接口。 |
| `每个接口只能列出一次。请删除 <interface> 的多余行。` | **监控接口** 中有两行指定了同一个接口。          |
| `委派前缀长度必须介于 48 到 64 之间。`           | 长度超出可接受的范围。                     |
| `请选择受支持的软件包计划。`                    | 计划不属于这四个选项之一。                   |
| `请为更新检查选择每天、每周、每月或从不。`             | **更新检查** 不属于这四个选项之一。            |

每次运行都会再次检查已保存的设置，因为表单保存后它们可能已被更改。运行可能报告的消息见[故障排除](/docs/operate/troubleshooting#run-failed)。
