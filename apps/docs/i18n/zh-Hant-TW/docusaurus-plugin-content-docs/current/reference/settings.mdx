查閱「設定」分頁上的每個欄位及其預設值與可接受的值。

## 前綴監控 \{#prefix-monitoring}

**Services → IPv6 Prefix Updater** 下的 **設定** 分頁以這些欄位開頭，儲存表單後會顯示 `設定已儲存。`

| 欄位                                                                                                                      | 說明                                                                                                                                                                                                                                                                                              |
|-------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="依排程自動檢查，啟用前一直關閉" to="/docs/reference/terminology#running-checks">啟用排程更新</Terminology>               | 依所選的 **排程** 執行檢查。預設關閉，儲存時會新增或移除 cron 項目。                                                                                                                                                                                                                                                        |
| <Terminology title="透過其位址揭示目前前綴的介面" to="/docs/reference/terminology#interfaces-and-detection">監控介面</Terminology>        | 必填。每個<Terminology title="位於 2000::/3 內的公用 IPv6 位址，唯一會用到的類型" to="/docs/reference/terminology#addresses-and-prefixes">全域位址</Terminology>承載<Terminology title="ISP 分配給你的 IPv6 網路，可能會變動" to="/docs/reference/terminology#addresses-and-prefixes">委派前綴</Terminology>的介面各有一列。**新增** 會新增一列，每個介面只能出現一次。 |
| <Terminology title="ISP 前綴的大小，例如 /56，由你設定" to="/docs/reference/terminology#addresses-and-prefixes">委派前綴長度</Terminology> | 每一列皆為必填。範圍為 `/48` 到 `/64`，預設選取 `/56`。                                                                                                                                                                                                                                                           |
| 排程                                                                                                                      | 每 15 分鐘、每小時、每 6 小時或每天午夜。預設為每小時。                                                                                                                                                                                                                                                                 |

## 欄位選取 \{#field-selection}

「設定」分頁會在 **排程** 下方顯示 `在「欄位」分頁中選擇哪些設定欄位隨前綴變更。` <Terminology title="一個開關管住一整類設定" to="/docs/reference/terminology#fields-and-change-plans">欄位群組</Terminology>與個別欄位都在 **欄位** 分頁中選擇，並與這些設定分開儲存，因此儲存「設定」分頁絕不會變更它們。每個群組及其預設值請見[欄位](/docs/configure/configuration-scopes)頁面。

## 套件更新 \{#package-updates}

| 欄位 | 說明 |
|-|-|
| 更新檢查 | 每天、每週、每月或永不。預設為每週。檢查會在固定的隨機時間執行。[更新](/docs/reference/updates)說明了它的作用。 |
| 遠端通知 | 預設關閉。同時透過 pfSense 中已設定的遠端通知管道（例如電子郵件、Telegram 或 Pushover）傳送每則新版本通知。 |

## 驗證訊息 \{#validation-messages}

| 訊息                                 | 原因                              |
|------------------------------------|---------------------------------|
| `請選擇要監控的已設定 pfSense 介面。`           | 沒有任何列，或某一列的介面不是已設定的 pfSense 介面。 |
| `每個介面只能列出一次。請移除 <interface> 的多餘列。` | **監控介面** 中有兩列指定了同一個介面。          |
| `委派前綴長度必須介於 48 到 64。`              | 長度超出可接受的範圍。                     |
| `請選擇支援的套件排程。`                      | 排程不屬於這四個選項之一。                   |
| `請為更新檢查選擇每天、每週、每月或永不。`             | **更新檢查** 不屬於這四個選項之一。            |

每次執行都會再次檢查已儲存的設定，因為表單儲存後它們可能已經變更。執行可能回報的訊息請見[疑難排解](/docs/operate/troubleshooting#run-failed)。
