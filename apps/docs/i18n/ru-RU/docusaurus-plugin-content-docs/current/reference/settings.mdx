Вкладка **Настройки** в **Services → IPv6 Prefix Updater** начинается с этих полей, а при сохранении формы появляется сообщение `Настройки сохранены.`

## Выбор полей \{#field-selection}

Под полем **Расписание** вкладка «Настройки» показывает `На вкладке «Поля» выберите, какие поля конфигурации меняются вместе с префиксом.` <Terminology title="Один переключатель на целый вид настроек" to="/docs/reference/terminology#fields-and-change-plans">Группы полей</Terminology> и отдельные поля выбираются на вкладке **Поля** и сохраняются отдельно от этих настроек, поэтому сохранение вкладки «Настройки» никогда их не изменяет. Каждая группа и её значение по умолчанию описаны в разделе [Поля](/docs/configure/configuration-scopes).

## Обновления пакета \{#package-updates}

| Поле | Описание |
|-|-|
| Проверка обновлений | Ежедневно, Еженедельно, Ежемесячно или Никогда. По умолчанию — Еженедельно. Проверка выполняется в постоянное случайно выбранное время. Что она делает, описано в разделе [Обновления](/docs/reference/updates). |
| Удалённые уведомления | По умолчанию выключено. Дополнительно отправляет каждое уведомление о новой версии через настроенные в pfSense удалённые каналы уведомлений, например электронную почту, Telegram или Pushover. |

## Сообщения проверки \{#validation-messages}

| Сообщение                                                                                | Причина                                                                                  |
|------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------|
| `Выберите настроенный интерфейс pfSense для контроля.`                                   | Нет ни одной строки, или интерфейс в строке не является настроенным интерфейсом pfSense. |
| `Каждый интерфейс можно указать только один раз. Удалите лишнюю строку для <interface>.` | Две строки в поле **Контролируемые интерфейсы** указывают один и тот же интерфейс.       |
| `Длина делегированного префикса должна быть от 48 до 64.`                                | Длина вне допустимого диапазона.                                                         |
| `Выберите поддерживаемое расписание пакета.`                                             | Расписание не входит в четыре доступных варианта.                                        |
| `Для проверки обновлений выберите Ежедневно, Еженедельно, Ежемесячно или Никогда.`       | Значение **Проверка обновлений** не входит в четыре доступных варианта.                  |

Каждый запуск снова проверяет сохранённые настройки, потому что они могли измениться после сохранения формы. Сообщения, которые может выдать запуск, перечислены в разделе [Устранение неполадок](/docs/operate/troubleshooting#run-failed).
