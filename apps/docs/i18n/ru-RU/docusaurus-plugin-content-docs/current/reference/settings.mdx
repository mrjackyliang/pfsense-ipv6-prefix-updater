Найдите любое поле вкладки «Настройки» вместе с его значением по умолчанию и допустимыми значениями.

Вкладка **Настройки** в **Services → IPv6 Prefix Updater** начинается с этих полей, а при сохранении формы появляется сообщение `Настройки сохранены.`

| <Terminology title="интерфейс, по адресу которого определяется текущий префикс" to="/docs/reference/terminology#monitored-interface">Контролируемые интерфейсы</Terminology>              | Обязательное. ## Выбор полей \{#field-selection}

Под полем **Расписание** вкладка «Настройки» показывает `На вкладке «Поля» выберите, какие поля конфигурации меняются вместе с префиксом.` <Terminology title="группа полей с одним переключателем на вкладке «Поля»" to="/docs/reference/terminology#field-group">Группы полей</Terminology> и отдельные поля выбираются на вкладке **Поля** и сохраняются отдельно от этих настроек, поэтому сохранение вкладки «Настройки» никогда их не изменяет. Каждая группа и её значение по умолчанию описаны в разделе [Поля](/docs/configure/configuration-scopes).

## Сообщения проверки \{#validation-messages}

| Сообщение                                                                                | Причина                                                                                  |
|------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------|
| `Выберите настроенный интерфейс pfSense для контроля.`                                   | Нет ни одной строки, или интерфейс в строке не является настроенным интерфейсом pfSense. |
| `Каждый интерфейс можно указать только один раз. Удалите лишнюю строку для <interface>.` | Две строки в поле **Контролируемые интерфейсы** указывают один и тот же интерфейс.       |
| `Длина делегированного префикса должна быть от 48 до 64.`                                | Длина вне допустимого диапазона.                                                         |
| `Выберите поддерживаемое расписание пакета.`                                             | Расписание не входит в четыре доступных варианта.                                        |

Каждый запуск снова проверяет сохранённые настройки, потому что они могли измениться после сохранения формы. Сообщения, которые может выдать запуск, перечислены в разделе [Устранение неполадок](/docs/operate/troubleshooting#run-failed).
