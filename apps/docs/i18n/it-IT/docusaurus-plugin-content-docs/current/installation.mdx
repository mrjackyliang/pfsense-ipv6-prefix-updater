Installa il pacchetto da una release GitHub con lo strumento `pkg` di pfSense, poi verifica che le sue pagine compaiano nella WebGUI.

## Requisiti \{#requirements}

- **Shell da amministratore** — Accesso SSH o da console alla shell di pfSense. Anche **Diagnostics → Command Prompt** nella WebGUI può eseguire singoli comandi.
- **Accesso HTTPS a GitHub** — Il firewall scarica il pacchetto da GitHub Releases.
- **Release pfSense supportata** — Usa pfSense CE 2.9.0 o 2.8.1, oppure pfSense Plus 26.07 o 26.03.1. La scheda **Informazioni** elenca le release di pfSense su cui è stata testata ogni versione del pacchetto.
- **Un backup recente** — Scarica una copia della configurazione da **Diagnostics → Backup & Restore** prima dell’installazione.
- **Il <Terminology title="Versione 1.x: lo script update.php avviato dal pacchetto Cron" to="/docs/reference/terminology#package-origins">vecchio script di aggiornamento</Terminology> può restare** — Se lo script della versione 1.x viene ancora eseguito dal pacchetto Cron, lascialo al suo posto. Il passaggio di installazione lo sposta nel pacchetto, come spiega [Migra dallo script](/docs/migrate-from-legacy).

:::warning

IPv6 Prefix Updater for pfSense è un <Terminology title="Installato da GitHub, non dal repository dei pacchetti di Netgate" to="/docs/reference/terminology#package-origins">pacchetto non ufficiale</Terminology>. Installare un file `.pkg` da GitHub aggira la revisione e il supporto dei pacchetti di Netgate, quindi è consigliabile provarlo prima su un firewall di cui hai un backup o su uno di prova.

:::

## Controlla la release \{#check-the-release}

Le release del pacchetto sono elencate nella [pagina GitHub Releases](https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases). Ogni release del pacchetto contiene questi file:

| File                                          | Descrizione                                                         |
|-----------------------------------------------|---------------------------------------------------------------------|
| `pfSense-pkg-Ipv6PrefixUpdater.pkg`           | Il pacchetto con un nome fisso, usato dai comandi di questa pagina. |
| `pfSense-pkg-Ipv6PrefixUpdater-<version>.pkg` | Lo stesso pacchetto con la versione nel nome del file.              |
| File `.sha256`                                | Un checksum SHA-256 per ogni file del pacchetto.                    |

:::info

Le release 1.x contengono solo il <Terminology title="Versione 1.x: lo script update.php avviato dal pacchetto Cron" to="/docs/reference/terminology#package-origins">vecchio script di aggiornamento</Terminology>. Se la release più recente non ha un file `.pkg`, i comandi di questa pagina falliscono con un errore 404 (non trovato).

:::

## Installa il pacchetto \{#install-the-package}

Esegui questo stesso comando dalla shell di pfSense per una prima installazione, un aggiornamento o una reinstallazione:

```shell
pkg add -f https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg
```

`pkg` scarica il pacchetto dalla release più recente ed esegue il suo passaggio di installazione, che registra **Services → IPv6 Prefix Updater** in pfSense. L’opzione `-f` consente allo stesso comando di installare il pacchetto, aggiornare una versione precedente o reinstallare la versione corrente. Senza questa opzione, pfSense CE 2.8 segnala che un aggiornamento è già installato e non modifica la versione installata.

## Verifica prima il download \{#verify-the-download-first}

Per confrontare il file con il suo checksum prima dell’installazione, scarica entrambi i file in `/tmp` e stampa entrambi i valori:

```shell
cd /tmp
fetch https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg
fetch https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg.sha256
sha256 -q pfSense-pkg-Ipv6PrefixUpdater.pkg
cat pfSense-pkg-Ipv6PrefixUpdater.pkg.sha256
```

Gli ultimi due comandi stampano lo stesso valore se il download è integro. Puoi quindi installare il file verificato con `pkg add -f /tmp/pfSense-pkg-Ipv6PrefixUpdater.pkg`.

## Conferma nella WebGUI \{#confirm-in-the-webgui}

1. Accedi alla WebGUI di pfSense.
2. Apri **Services → IPv6 Prefix Updater** e verifica che compaiano le schede **Impostazioni**, **Stato**, **Campi**, **Backup**, **Pulizia** e **Informazioni**.
3. Nella scheda Stato, verifica che **Stato attuale** mostri `Nessuna interfaccia monitorata è ancora salvata. Aggiungile nella scheda Impostazioni.` Dopo la migrazione dal vecchio script di aggiornamento, elenca invece le interfacce spostate.
4. Lascia deselezionato **<Terminology title="Controlli automatici pianificati, spenti finché non li attivi" to="/docs/reference/terminology#running-checks">Abilita aggiornamenti pianificati</Terminology>**, come da impostazione predefinita, finché non hai [stabilito la linea di base](/docs/first-run). Dopo la migrazione dal vecchio script di aggiornamento è già selezionato, in linea con la vecchia pianificazione Cron.

## Se l’installazione non riesce \{#if-installation-fails}

- **Non trovato (404)**: la release più recente non ha un file del pacchetto. [Controlla la release](/docs/installation#check-the-release) spiega quali release ne contengono uno.
- **Architettura errata su pfSense CE 2.9.0**: le release fino alla 2.0.1 inclusa sono state compilate solo per FreeBSD 15, quindi pfSense CE 2.9.0 mostra un messaggio di architettura errata per queste versioni. Installa la release più recente.
- **Errori DNS, TLS o di certificato**: pfSense deve risolvere `github.com`, raggiungerlo tramite HTTPS e mantenere l’ora corretta per il controllo dei certificati.

Continua con [Stabilisci la linea di base](/docs/first-run) quando il pacchetto compare nella WebGUI.
