Instale o pacote a partir de uma versão publicada no GitHub com a ferramenta `pkg` do pfSense e depois confirme se as páginas dele aparecem na WebGUI.

## Requisitos \{#requirements}

- **Shell de administrador** — Acesso SSH ou pelo console ao shell do pfSense. Também é possível executar comandos avulsos em **Diagnostics → Command Prompt**, na WebGUI.
- **Acesso HTTPS ao GitHub** — O firewall baixa o pacote das GitHub Releases.
- **Versão compatível do pfSense** — Use o pfSense CE 2.9.1, 2.9.0 ou 2.8.1, ou o pfSense Plus 26.07.1, 26.07 ou 26.03.1. A guia **Sobre** lista as versões do pfSense nas quais cada versão do pacote foi testada.
- **Um backup recente** — Baixe uma cópia da configuração em **Diagnostics → Backup & Restore** antes de instalar.
- **O <Terminology title="Versão 1.x: o script update.php executado pelo pacote Cron" to="/docs/reference/terminology#package-origins">atualizador legado</Terminology> pode ficar** — Se o script da versão 1.x ainda roda pelo pacote Cron, deixe-o onde está. A etapa de instalação o move para o pacote, como explica [Migrar do script](/docs/migrate-from-legacy).

:::warning

O IPv6 Prefix Updater for pfSense é um <Terminology title="Instalado pelo GitHub, não pelo repositório de pacotes da Netgate" to="/docs/reference/terminology#package-origins">pacote não oficial</Terminology>. Instalar um arquivo `.pkg` do GitHub contorna a revisão e o suporte de pacotes da Netgate, por isso é recomendável testá-lo primeiro em um firewall com backup ou descartável.

:::

## Conferir a versão \{#check-the-release}

As versões do pacote ficam listadas na [página GitHub Releases](https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases). Cada versão do pacote traz estes arquivos:

| Arquivo                                       | Descrição                                                     |
|-----------------------------------------------|---------------------------------------------------------------|
| `pfSense-pkg-Ipv6PrefixUpdater.pkg`           | O pacote com um nome fixo, usado pelos comandos desta página. |
| `pfSense-pkg-Ipv6PrefixUpdater-<version>.pkg` | O mesmo pacote com a versão no nome do arquivo.               |
| Arquivos `.sha256`                            | Um checksum SHA-256 para cada arquivo do pacote.              |

:::info

As versões 1.x contêm apenas o <Terminology title="Versão 1.x: o script update.php executado pelo pacote Cron" to="/docs/reference/terminology#package-origins">atualizador legado</Terminology>. Se a versão mais recente não tiver um arquivo `.pkg`, os comandos desta página falham com um erro 404 (não encontrado).

:::

## Instalar o pacote \{#install-the-package}

Execute este mesmo comando no shell do pfSense em uma primeira instalação, atualização ou reinstalação:

```shell
pkg add -f https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg
```

O `pkg` baixa o pacote da versão mais recente e executa a etapa de instalação, que registra **Services → IPv6 Prefix Updater** no pfSense. A opção `-f` permite que o mesmo comando instale o pacote, atualize uma versão mais antiga ou reinstale a versão atual. Sem ela, o pfSense CE 2.8 informa que uma atualização já está instalada e não altera a versão instalada.

## Conferir o download antes \{#verify-the-download-first}

Para comparar o arquivo com o checksum antes de instalar, baixe os dois arquivos para `/tmp` e exiba os dois valores:

```shell
cd /tmp
fetch https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg
fetch https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg.sha256
sha256 -q pfSense-pkg-Ipv6PrefixUpdater.pkg
cat pfSense-pkg-Ipv6PrefixUpdater.pkg.sha256
```

Os dois últimos comandos exibem o mesmo valor quando o download está íntegro. Depois, você pode instalar o arquivo conferido com `pkg add -f /tmp/pfSense-pkg-Ipv6PrefixUpdater.pkg`.

## Confirmar na WebGUI \{#confirm-in-the-webgui}

1. Faça login na WebGUI do pfSense.
2. Abra **Services → IPv6 Prefix Updater** e confirme que as guias **Configurações**, **Status**, **Campos**, **Backups**, **Limpeza** e **Sobre** aparecem.
3. Na guia Status, confirme que **Estado atual** mostra `Ainda não há interfaces monitoradas salvas. Adicione-as na guia Configurações.` Após a migração do atualizador legado, ele mostra as interfaces migradas em vez dessa mensagem.
4. Deixe a opção **<Terminology title="Verificações automáticas agendadas, desligadas até você ativar" to="/docs/reference/terminology#running-checks">Ativar atualizações agendadas</Terminology>** desmarcada, como vem por padrão, até [estabelecer a referência](/docs/first-run). Após a migração do atualizador legado, ela já vem marcada, de acordo com o antigo agendamento do Cron.

## Se a instalação falhar \{#if-installation-fails}

- **Não encontrado (404)**: a versão mais recente não tem arquivo de pacote. [Conferir a versão](/docs/installation#check-the-release) explica quais versões trazem um.
- **Arquitetura incorreta no pfSense CE 2.9.0**: as versões até a 2.0.1, inclusive, foram compiladas apenas para o FreeBSD 15, portanto o pfSense CE 2.9.0 exibe uma mensagem de arquitetura incorreta para elas. Instale a versão mais recente.
- **Erros de DNS, TLS ou certificado**: o pfSense precisa resolver `github.com`, acessá-lo por HTTPS e manter o horário correto para validar certificados.

Siga para [Estabelecer a referência](/docs/first-run) assim que o pacote aparecer na WebGUI.
