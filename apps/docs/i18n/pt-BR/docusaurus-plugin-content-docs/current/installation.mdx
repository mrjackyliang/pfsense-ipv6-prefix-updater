Instale o pacote a partir de uma versão publicada no GitHub com a ferramenta `pkg` do pfSense e depois confirme se as páginas dele aparecem na WebGUI.

## Requisitos \{#requirements}

- **Shell de administrador** — Acesso SSH ou pelo console ao shell do pfSense. Também é possível executar comandos avulsos em **Diagnostics → Command Prompt**, na WebGUI.
- **Acesso HTTPS ao GitHub** — O firewall baixa o pacote das GitHub Releases.
- **Um build compatível do pacote** — O pacote precisa ser compilado para a versão do FreeBSD usada pela sua versão do pfSense.
- **Um backup recente** — Baixe uma cópia da configuração em **Diagnostics → Backup & Restore** antes de instalar.
- **O <Terminology title="script update.php original executado pelo pacote Cron" to="/docs/reference/terminology#legacy-updater">atualizador legado</Terminology> pode ficar** — Se o script da versão 1.x ainda roda pelo pacote Cron, deixe-o onde está. A etapa de instalação o move para o pacote, como explica [Migrar do script](/docs/migrate-from-legacy).

:::warning

O pfSense IPv6 Prefix Updater é um <Terminology title="pacote instalado do GitHub, não do repositório da Netgate" to="/docs/reference/terminology#unofficial-package">pacote não oficial</Terminology>. Instalar um arquivo `.pkg` do GitHub contorna a revisão e o suporte de pacotes da Netgate, por isso é recomendável testá-lo primeiro em um firewall com backup ou descartável.

:::

## Conferir a versão \{#check-the-release}

As versões do pacote ficam listadas na [página GitHub Releases](https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases). Cada versão do pacote traz estes arquivos:

| Arquivo                                       | Descrição                                                     |
|-----------------------------------------------|---------------------------------------------------------------|
| `pfSense-pkg-Ipv6PrefixUpdater.pkg`           | O pacote com um nome fixo, usado pelos comandos desta página. |
| `pfSense-pkg-Ipv6PrefixUpdater-<version>.pkg` | O mesmo pacote com a versão no nome do arquivo.               |
| Arquivos `.sha256`                            | Um checksum SHA-256 para cada arquivo do pacote.              |

:::info

As versões 1.x contêm apenas o <Terminology title="script update.php original executado pelo pacote Cron" to="/docs/reference/terminology#legacy-updater">atualizador legado</Terminology>. Se a versão mais recente não tiver um arquivo `.pkg`, os comandos desta página falham com um erro 404 (não encontrado).

:::

## Instalar o pacote \{#install-the-package}

Execute este comando no shell do pfSense:

```shell
pkg add https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg
```

O `pkg` baixa o pacote da versão mais recente e executa a etapa de instalação, que registra **Services → IPv6 Prefix Updater** no pfSense.

## Conferir o download antes \{#verify-the-download-first}

Para comparar o arquivo com o checksum antes de instalar, baixe os dois arquivos para `/tmp` e exiba os dois valores:

```shell
cd /tmp
fetch https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg
fetch https://github.com/mrjackyliang/pfsense-ipv6-prefix-updater/releases/latest/download/pfSense-pkg-Ipv6PrefixUpdater.pkg.sha256
sha256 -q pfSense-pkg-Ipv6PrefixUpdater.pkg
cat pfSense-pkg-Ipv6PrefixUpdater.pkg.sha256
```

Os dois últimos comandos exibem o mesmo valor quando o download está íntegro. Depois, você pode instalar o arquivo conferido com `pkg add /tmp/pfSense-pkg-Ipv6PrefixUpdater.pkg`.

## Confirmar na WebGUI \{#confirm-in-the-webgui}

1. Faça login na WebGUI do pfSense.
2. Abra **Services → IPv6 Prefix Updater** e confirme que as guias **Configurações**, **Status**, **Campos**, **Backups** e **Limpeza** aparecem.
3. Na guia Status, confirme que **Estado atual** mostra `Ainda não há interfaces monitoradas salvas. Adicione-as na guia Configurações.` Após a migração do atualizador legado, ele mostra as interfaces migradas em vez dessa mensagem.
4. Deixe a opção **<Terminology title="verificações automáticas por entrada cron gerenciada pelo pfSense" to="/docs/reference/terminology#scheduled-updates">Ativar atualizações agendadas</Terminology>** desmarcada, como vem por padrão, até [estabelecer a referência](/docs/first-run). Após a migração do atualizador legado, ela já vem marcada, de acordo com o antigo agendamento do Cron.

## Se a instalação falhar \{#if-installation-fails}

- **Não encontrado (404)**: a versão mais recente não tem arquivo de pacote. [Conferir a versão](/docs/installation#check-the-release) explica quais versões trazem um.
- **Incompatibilidade de ABI ou de versão do sistema operacional**: o pacote foi compilado para uma versão do FreeBSD diferente da usada pela sua versão do pfSense. É recomendável usar um build compatível em vez de forçar a instalação.
- **Erros de DNS, TLS ou certificado**: o pfSense precisa resolver `github.com`, acessá-lo por HTTPS e manter o horário correto para validar certificados.

Siga para [Estabelecer a referência](/docs/first-run) assim que o pacote aparecer na WebGUI.
