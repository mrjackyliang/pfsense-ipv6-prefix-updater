Consulte cada campo da guia Configurações com o valor padrão e os valores que ele aceita.

## Monitorização do prefixo \{#prefix-monitoring}

A guia **Configurações** em **Services → IPv6 Prefix Updater** começa com estes campos, e salvar o formulário mostra `Configurações salvas.`

| Campo                                                                                                                                                                                  | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="Verificações automáticas agendadas, desligadas até você ativar" to="/docs/reference/terminology#running-checks">Ativar atualizações agendadas</Terminology>        | Executa verificações no **Agendamento** selecionado. Desmarcada por padrão, e salvar adiciona ou remove a entrada cron.                                                                                                                                                                                                                                                                                                                                                        |
| <Terminology title="A interface cujo endereço revela seu prefixo atual" to="/docs/reference/terminology#interfaces-and-detection">Interfaces monitoradas</Terminology>                 | Obrigatório. Uma linha para cada interface cujo <Terminology title="Um endereço IPv6 público em 2000::/3, o único tipo usado" to="/docs/reference/terminology#addresses-and-prefixes">endereço global</Terminology> contém um <Terminology title="A rede IPv6 que seu provedor entrega, e que pode mudar" to="/docs/reference/terminology#addresses-and-prefixes">prefixo delegado</Terminology>. **Adicionar** adiciona uma linha, e cada interface só pode aparecer uma vez. |
| <Terminology title="O tamanho do prefixo do seu provedor, como /56; você define" to="/docs/reference/terminology#addresses-and-prefixes">Comprimento do prefixo delegado</Terminology> | Obrigatório em cada linha. De `/48` a `/64`, com `/56` selecionado por padrão.                                                                                                                                                                                                                                                                                                                                                                                                 |
| Agendamento                                                                                                                                                                            | A cada 15 minutos, A cada hora, A cada 6 horas ou Diariamente à meia-noite. A cada hora por padrão.                                                                                                                                                                                                                                                                                                                                                                            |

## Seleção de campos \{#field-selection}

Abaixo do campo **Agendamento**, a guia Configurações mostra `Escolha na guia Campos quais campos da configuração mudam com o prefixo.` Os <Terminology title="Um único botão para um tipo inteiro de configuração" to="/docs/reference/terminology#fields-and-change-plans">grupos de campos</Terminology> e os campos individuais são escolhidos na guia **Campos** e salvos separadamente destas configurações, então salvar a guia Configurações nunca os altera. A página [Campos](/docs/configure/configuration-scopes) descreve cada grupo e o padrão dele.

## Notificações \{#notifications}

| Campo                                                                                                                                                                                    | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="O alerta enviado depois que seus endereços foram atualizados" to="/docs/reference/terminology#notifications-and-logs">Enviar notificações de alteração</Terminology> | Marcado por padrão. Envia uma <Terminology title="O alerta enviado depois que seus endereços foram atualizados" to="/docs/reference/terminology#notifications-and-logs">notificação de alteração</Terminology> após cada <Terminology title="O prefixo mudou e cada campo aprovado foi atualizado" to="/docs/reference/terminology#run-outcomes">Sucesso</Terminology>, enquanto os alertas de <Terminology title="O prefixo mudou, mas nenhum campo aprovado usava o antigo" to="/docs/reference/terminology#run-outcomes">Aviso</Terminology> e <Terminology title="A execução parou em uma verificação ou etapa de segurança" to="/docs/reference/terminology#run-outcomes">Falha</Terminology> aparecem de qualquer forma. |

## Atualizações do pacote \{#package-updates}

| Campo | Descrição |
|-|-|
| Verificações de atualizações | Diariamente, Semanalmente, Mensalmente ou Nunca. Semanalmente por padrão. A verificação é executada em um horário aleatório estável. [Atualizações](/docs/reference/updates) descreve o que ela faz. |
| Notificações remotas | Desmarcada por padrão. Também envia cada alerta de nova versão pelos canais de notificação remota configurados no pfSense, como e-mail, Telegram ou Pushover. |

## Mensagens de validação \{#validation-messages}

| Mensagem                                                                                          | Causa                                                                                             |
|---------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------|
| `Selecione uma interface pfSense configurada para monitorar.`                                     | Não existe nenhuma linha, ou a interface de uma linha não é uma interface configurada do pfSense. |
| `Cada interface só pode aparecer uma vez. Remova a linha extra de <interface>.`                   | Duas linhas de **Interfaces monitoradas** indicam a mesma interface.                              |
| `O comprimento do prefixo delegado deve estar entre 48 e 64.`                                     | O comprimento está fora do intervalo aceito.                                                      |
| `Selecione um agendamento de pacote compatível.`                                                  | O agendamento não é uma das quatro opções.                                                        |
| `Selecione Diariamente, Semanalmente, Mensalmente ou Nunca para as verificações de atualizações.` | **Verificações de atualizações** não é uma das quatro opções.                                     |

Cada execução confere as configurações salvas de novo, porque elas podem ter mudado depois que o formulário foi salvo. A página [Solução de problemas](/docs/operate/troubleshooting#run-failed) lista as mensagens que uma execução pode informar.
