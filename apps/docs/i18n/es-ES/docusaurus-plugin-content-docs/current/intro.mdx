Mantén las direcciones IPv6 guardadas en pfSense en tu prefijo actual cuando tu ISP asigna un nuevo <Terminology title="La red IPv6 que te asigna tu proveedor, y que puede cambiar" to="/docs/reference/terminology#addresses-and-prefixes">prefijo delegado</Terminology>.

## Qué hace \{#what-it-does}

IPv6 Prefix Updater for pfSense es un paquete de pfSense que vigila las interfaces que eliges a la espera de un nuevo prefijo. Cuando el prefijo cambia, reescribe las direcciones que coinciden en los campos que seleccionas y conserva la <Terminology title="Los bits después del prefijo, que siempre se copian sin cambios" to="/docs/reference/terminology#addresses-and-prefixes">parte de host</Terminology> de cada una.

## ¿Por qué usar este paquete? \{#why-use-this-package}

1. Conserva la <Terminology title="Los bits después del prefijo, que siempre se copian sin cambios" to="/docs/reference/terminology#addresses-and-prefixes">parte de host</Terminology> de cada dirección para que cada dispositivo mantenga el mismo sufijo después de un cambio de prefijo.
2. Cambia solo los <Terminology title="Un ajuste que el paquete tiene permiso para reescribir" to="/docs/reference/terminology#fields-and-change-plans">campos aprobados</Terminology> que seleccionas en la pestaña Campos, para que las redes VPN remotas, los pares, las puertas de enlace y las rutas sigan tal como los configuraste.
3. Guarda una <Terminology title="Una copia de la configuración tomada justo antes de escribir" to="/docs/reference/terminology#backups-and-service-reloads">copia de seguridad de la configuración</Terminology> antes de cada escritura para que la configuración anterior quede disponible en el <Terminology title="Las revisiones de configuración guardadas en pfSense que puedes restaurar" to="/docs/reference/terminology#backups-and-service-reloads">historial de configuración</Terminology>.
4. Se ejecuta con una programación que gestiona pfSense, así que no necesitas el paquete Cron ni un script en un directorio personal.
5. Muestra cada resultado en la pestaña Estado para que puedas ver qué cambió, qué servicios se recargaron y si se hizo una copia de seguridad.

## Qué actualiza \{#what-it-updates}

- **Alias**: direcciones y redes de los alias de host y de red.
- **Interfaces estáticas**: direcciones de las interfaces configuradas como Static IPv6.
- **<Terminology title="Una dirección extra en una interfaz, como una VIP de CARP" to="/docs/reference/terminology#pfsense-features">Direcciones IP virtuales</Terminology>**: <Terminology title="Una dirección extra en una interfaz, como una VIP de CARP" to="/docs/reference/terminology#pfsense-features">IP virtuales</Terminology> CARP e IP Alias.
- **IPsec**: el extremo local de las entradas de <Terminology title="La entrada IPsec que define las redes local y remota de un túnel" to="/docs/reference/terminology#pfsense-features">fase 2</Terminology> Tunnel IPv6 y Routed (VTI).
- **OpenVPN**: redes de túnel y redes locales IPv6 en servidores y <Terminology title="Ajustes de OpenVPN que se aplican a un solo cliente" to="/docs/reference/terminology#pfsense-features">anulaciones específicas de cliente</Terminology>, y redes de túnel IPv6 en clientes.
- **WireGuard**: <Terminology title="La dirección de una interfaz de túnel WireGuard" to="/docs/reference/terminology#pfsense-features">direcciones de túnel</Terminology>, cuando el paquete WireGuard está instalado.
- **Servidor DHCPv6**: rangos de direcciones, de delegación de prefijos y de pools, asignaciones estáticas, y los servidores DNS y NTP que se entregan a los clientes.
- **Anuncios de enrutador**: servidores DNS y subredes RA anunciados.
- **Anulaciones de host DNS**: anulaciones de host del DNS Resolver y del DNS Forwarder.
- **Reglas del cortafuegos**: direcciones de origen y destino escritas en las reglas.
- **NAT y NPt**: direcciones escritas en redirecciones de puertos, NAT saliente y NAT 1:1, y prefijos NPt.
- **Ajustes de otros paquetes**: solo los campos que marcas, tras lo cual el paquete vuelve a aplicar los ajustes de ese paquete.

La pestaña **Campos** enumera todas las direcciones de tu prefijo, con un interruptor para cada <Terminology title="Un solo interruptor para todo un tipo de ajuste" to="/docs/reference/terminology#fields-and-change-plans">grupo de campos</Terminology> y una casilla para cada campo.

## Qué te espera \{#what-waits-for-you}

El grupo **Otra configuración** empieza desactivado, así que estos valores solo cambian cuando los marcas:

- El extremo remoto de una VPN, como las redes remotas de IPsec y OpenVPN, y los pares, las IP permitidas y los puntos finales de WireGuard.
- Las puertas de enlace, las rutas estáticas, las anulaciones de dominio DNS, los certificados, los secretos, los valores codificados en Base64 y las descripciones.
- Los alias de puerto, de URL y de otros tipos.

Las interfaces que obtienen su dirección por DHCPv6, SLAAC o <Terminology title="Una interfaz que forma su IPv6 a partir del prefijo de otra" to="/docs/reference/terminology#interfaces-and-detection">Track Interface</Terminology> nunca se modifican, porque pfSense genera esas direcciones. Tampoco las direcciones IPv4, los nombres de host ni las direcciones IPv6 fuera del prefijo anterior. [Otra configuración](/docs/configure/configuration-scopes#other-settings) tiene la lista completa.

## Cómo funciona una comprobación \{#how-a-check-works}

1. Lee la <Terminology title="Una dirección IPv6 pública en 2000::/3, la única que se usa" to="/docs/reference/terminology#addresses-and-prefixes">dirección global</Terminology> de cada <Terminology title="La interfaz cuya dirección revela tu prefijo actual" to="/docs/reference/terminology#interfaces-and-detection">Interfaz supervisada</Terminology> y calcula su prefijo.
2. Lo compara con el <Terminology title="El prefijo guardado con el que compara cada comprobación" to="/docs/reference/terminology#baselines-and-transitions">último prefijo correcto</Terminology> y se detiene con <Terminology title="El mismo prefijo que la última vez, así que no hay nada que hacer" to="/docs/reference/terminology#run-outcomes">Sin cambios</Terminology> si coinciden.
3. Ante un <Terminology title="Tu prefijo cambió, así que el paquete se pone a trabajar" to="/docs/reference/terminology#baselines-and-transitions">cambio de prefijo</Terminology>, crea un <Terminology title="Cada reescritura prevista, preparada antes de cambiar nada" to="/docs/reference/terminology#fields-and-change-plans">plan de cambios</Terminology> para los <Terminology title="Un ajuste que el paquete tiene permiso para reescribir" to="/docs/reference/terminology#fields-and-change-plans">campos aprobados</Terminology> que todavía usan el prefijo anterior.
4. Guarda una <Terminology title="Una copia de la configuración tomada justo antes de escribir" to="/docs/reference/terminology#backups-and-service-reloads">copia de seguridad de la configuración</Terminology>, escribe todos los cambios de una sola vez, recarga solo los servicios afectados y vuelve a comprobar los valores.
5. Registra el resultado en la pestaña Estado y envía una <Terminology title="El aviso que se envía después de actualizar tus direcciones" to="/docs/reference/terminology#notifications-and-logs">notificación de cambios</Terminology> si está activada.

[Modelo de seguridad](/docs/operations) explica las protecciones de cada paso.

## Antes de empezar \{#before-you-start}

:::warning

IPv6 Prefix Updater for pfSense es un <Terminology title="Instalado desde GitHub, no desde el repositorio de paquetes de Netgate" to="/docs/reference/terminology#package-origins">paquete no oficial</Terminology>. Lo instalas desde GitHub con `pkg`, y Netgate no lo revisa ni le da soporte.

:::

Las versiones del paquete se publican en la página GitHub Releases del proyecto. Las versiones 1.x solo contienen el <Terminology title="Versión 1.x: el script update.php ejecutado por el paquete Cron" to="/docs/reference/terminology#package-origins">actualizador heredado</Terminology>, no este paquete.

## Idiomas \{#languages}

Todas las pestañas del paquete, la <Terminology title="Las líneas de la última ejecución, justo después de iniciarla" to="/docs/reference/terminology#running-checks">Salida del comando</Terminology> y los mensajes del paquete siguen el idioma seleccionado en pfSense. El paquete incluye traducciones para 18 opciones de idioma de pfSense y recurre al inglés para cualquier otro idioma.
