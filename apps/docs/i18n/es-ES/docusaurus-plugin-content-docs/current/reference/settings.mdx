Consulta cada campo de la pestaña Configuración con su valor predeterminado y los valores que acepta.

## Supervisión del prefijo \{#prefix-monitoring}

La pestaña **Configuración** de **Services → IPv6 Prefix Updater** empieza con estos campos, y al guardar el formulario se muestra `Configuración guardada.`

| Campo                                                                                                                                                                                       | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="Comprobaciones automáticas programadas, apagadas por defecto" to="/docs/reference/terminology#running-checks">Activar actualizaciones programadas</Terminology>         | Ejecuta comprobaciones según la **Programación** seleccionada. Desactivado de forma predeterminada; al guardar se añade o se elimina la entrada de cron.                                                                                                                                                                                                                                                                                                                       |
| <Terminology title="La interfaz cuya dirección revela tu prefijo actual" to="/docs/reference/terminology#interfaces-and-detection">Interfaces supervisadas</Terminology>                    | Obligatorio. Una fila por cada interfaz cuya <Terminology title="Una dirección IPv6 pública en 2000::/3, la única que se usa" to="/docs/reference/terminology#addresses-and-prefixes">dirección global</Terminology> lleva un <Terminology title="La red IPv6 que te asigna tu proveedor, y que puede cambiar" to="/docs/reference/terminology#addresses-and-prefixes">prefijo delegado</Terminology>. **Añadir** añade una fila, y cada interfaz solo puede aparecer una vez. |
| <Terminology title="Qué tamaño tiene el prefijo de tu proveedor, como /56; lo fijas tú" to="/docs/reference/terminology#addresses-and-prefixes">Longitud del prefijo delegado</Terminology> | Obligatorio en cada fila. De `/48` a `/64`, con `/56` seleccionado de forma predeterminada.                                                                                                                                                                                                                                                                                                                                                                                    |
| Programación                                                                                                                                                                                | Cada 15 minutos, Cada hora, Cada 6 horas o Todos los días a medianoche. Cada hora de forma predeterminada.                                                                                                                                                                                                                                                                                                                                                                     |

## Selección de campos \{#field-selection}

Debajo de **Programación**, la pestaña Configuración muestra `Elija en la pestaña Campos qué campos de la configuración cambian con el prefijo.` Los <Terminology title="Un solo interruptor para todo un tipo de ajuste" to="/docs/reference/terminology#fields-and-change-plans">grupos de campos</Terminology> y los campos individuales se eligen en la pestaña **Campos** y se guardan aparte de estos ajustes, así que guardar la pestaña Configuración nunca los cambia. [Campos](/docs/configure/configuration-scopes) describe cada grupo y su valor predeterminado.

## Notificaciones \{#notifications}

| Campo                                                                                                                                                                                   | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="El aviso que se envía después de actualizar tus direcciones" to="/docs/reference/terminology#notifications-and-logs">Enviar notificaciones de cambios</Terminology> | Marcado de forma predeterminada. Envía una <Terminology title="El aviso que se envía después de actualizar tus direcciones" to="/docs/reference/terminology#notifications-and-logs">notificación de cambios</Terminology> tras cada resultado <Terminology title="El prefijo cambió y se actualizó cada campo aprobado" to="/docs/reference/terminology#run-outcomes">Correcto</Terminology>, mientras que los avisos de <Terminology title="El prefijo cambió, pero ningún campo aprobado usaba el anterior" to="/docs/reference/terminology#run-outcomes">Advertencia</Terminology> y <Terminology title="La ejecución se detuvo en una comprobación o etapa de seguridad" to="/docs/reference/terminology#run-outcomes">Fallo</Terminology> aparecen en cualquier caso. |

## Actualizaciones del paquete \{#package-updates}

| Campo | Descripción |
|-|-|
| Comprobaciones de actualizaciones | Diariamente, Semanalmente, Mensualmente o Nunca. Semanalmente de forma predeterminada. La comprobación se ejecuta a una hora aleatoria estable. [Actualizaciones](/docs/reference/updates) describe lo que hace. |
| Notificaciones remotas | Desactivada de forma predeterminada. También envía cada aviso de nueva versión a través de los canales de notificación remota configurados en pfSense, como el correo electrónico, Telegram o Pushover. |

## Mensajes de validación \{#validation-messages}

| Mensaje                                                                                                  | Causa                                                                                     |
|----------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------|
| `Seleccione una interfaz pfSense configurada para supervisar.`                                           | No hay ninguna fila, o la interfaz de una fila no es una interfaz de pfSense configurada. |
| `Cada interfaz solo puede figurar una vez. Quite la fila adicional de <interfaz>.`                       | Dos filas de **Interfaces supervisadas** indican la misma interfaz.                       |
| `La longitud del prefijo delegado debe estar entre 48 y 64.`                                             | La longitud está fuera del intervalo aceptado.                                            |
| `Seleccione una programación compatible con el paquete.`                                                 | La programación no es ninguna de las cuatro opciones.                                     |
| `Selecciona Diariamente, Semanalmente, Mensualmente o Nunca para las comprobaciones de actualizaciones.` | **Comprobaciones de actualizaciones** no es ninguna de las cuatro opciones.               |

Cada ejecución vuelve a comprobar los ajustes guardados, porque podrían haber cambiado después de guardar el formulario. [Solución de problemas](/docs/operate/troubleshooting#run-failed) enumera los mensajes que puede dar una ejecución.
