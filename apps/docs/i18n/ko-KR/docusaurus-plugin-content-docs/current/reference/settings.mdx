설정 탭의 모든 필드를 기본값 및 허용되는 값과 함께 찾아봅니다.

## 접두사 모니터링 \{#prefix-monitoring}

**Services → IPv6 Prefix Updater** 아래의 **설정** 탭은 다음 필드로 시작하며, 양식을 저장하면 `설정이 저장되었습니다.`가 표시됩니다.

| 필드                                                                                                                                  | 설명                                                                                                                                                                                                                                                                                                                             |
|-------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="pfSense가 관리하는 cron 항목으로 실행하는 자동 확인" to="/docs/reference/terminology#scheduled-updates">예약 업데이트 사용</Terminology> | 선택한 **일정**에 따라 확인을 실행합니다. 기본적으로 꺼져 있으며, 저장하면 cron 항목이 추가되거나 제거됩니다.                                                                                                                                                                                                                                                             |
| <Terminology title="주소로 현재 접두사를 알려 주는 인터페이스" to="/docs/reference/terminology#monitored-interface">모니터링할 인터페이스</Terminology>         | 필수입니다. <Terminology title="2000::/3 범위의 공인 IPv6 주소" to="/docs/reference/terminology#global-unicast-address">글로벌 주소</Terminology>가 <Terminology title="ISP가 방화벽으로 라우팅하는 IPv6 네트워크" to="/docs/reference/terminology#delegated-prefix">위임된 접두사</Terminology>를 담고 있는 인터페이스마다 한 행씩 있습니다. **추가**로 행을 추가하며, 각 인터페이스는 한 번만 나타날 수 있습니다. |
| <Terminology title="ISP 접두사 크기 설정, /48~/64" to="/docs/reference/terminology#delegated-prefix-length">위임된 접두사 길이</Terminology>       | 각 행에서 필수입니다. `/48`부터 `/64`까지이며, 기본으로 `/56`이 선택되어 있습니다.                                                                                                                                                                                                                                                                         |
| 일정                                                                                                                                  | 15분마다, 매시간, 6시간마다, 매일 자정 중 하나입니다. 기본값은 매시간입니다.                                                                                                                                                                                                                                                                                 |

## 필드 선택 \{#field-selection}

설정 탭의 **일정** 아래에는 `필드 탭에서 접두사와 함께 변경할 구성 필드를 선택하십시오.`가 표시됩니다. <Terminology title="필드 탭에서 스위치 하나로 켜고 끄는 필드 묶음" to="/docs/reference/terminology#field-group">필드 그룹</Terminology>과 개별 필드는 **필드** 탭에서 선택하며 이 설정과 별도로 저장되므로, 설정 탭을 저장해도 바뀌지 않습니다. 각 그룹과 그 기본값은 [필드](/docs/configure/configuration-scopes)에서 설명합니다.

## 알림 \{#notifications}

| 필드                                                                                                                       | 설명                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|--------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="검증된 업데이트가 성공한 뒤 보내는 알림" to="/docs/reference/terminology#change-notification">변경 알림 보내기</Terminology> | 기본으로 선택되어 있습니다. 각 <Terminology title="결과: 필드 업데이트, 저장, 다시 로드, 검증 완료" to="/docs/reference/terminology#success">성공</Terminology> 후에 <Terminology title="검증된 업데이트가 성공한 뒤 보내는 알림" to="/docs/reference/terminology#change-notification">변경 알림</Terminology>을 보내며, <Terminology title="결과: 접두사가 바뀌었지만 일치하는 승인된 필드 없음" to="/docs/reference/terminology#warning">경고</Terminology> 및 <Terminology title="결과: 검사나 안전 단계가 실행을 중단함" to="/docs/reference/terminology#failure">실패</Terminology> 알림은 이 설정과 관계없이 표시됩니다. |

## 유효성 검사 메시지 \{#validation-messages}

| 메시지                                                       | 원인                                            |
|-----------------------------------------------------------|-----------------------------------------------|
| `모니터링할 구성된 pfSense 인터페이스를 선택하십시오.`                        | 행이 없거나, 어떤 행의 인터페이스가 구성된 pfSense 인터페이스가 아닙니다. |
| `각 인터페이스는 한 번만 나열할 수 있습니다. <interface>에 대한 추가 행을 제거하십시오.` | 두 **모니터링할 인터페이스** 행이 같은 인터페이스를 지정합니다.         |
| `위임된 접두사 길이는 48에서 64 사이여야 합니다.`                           | 길이가 허용 범위를 벗어났습니다.                            |
| `지원되는 패키지 일정을 선택하십시오.`                                    | 일정이 네 가지 옵션 중 하나가 아닙니다.                       |

양식을 저장한 뒤 설정이 바뀌었을 수 있으므로 각 실행은 저장된 설정을 다시 검사합니다. 실행이 보고할 수 있는 메시지는 [문제 해결](/docs/operate/troubleshooting#run-failed)에 나와 있습니다.
