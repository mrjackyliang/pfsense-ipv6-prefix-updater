설정 탭의 모든 필드를 기본값 및 허용되는 값과 함께 찾아봅니다.

## 접두사 모니터링 \{#prefix-monitoring}

**Services → IPv6 Prefix Updater** 아래의 **설정** 탭은 다음 필드로 시작하며, 양식을 저장하면 `설정이 저장되었습니다.`가 표시됩니다.

| 필드                                                                                                                                 | 설명                                                                                                                                                                                                                                                                                                                                                    |
|------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="일정에 따른 자동 확인으로, 켜기 전까지는 꺼져 있음" to="/docs/reference/terminology#running-checks">예약 업데이트 사용</Terminology>        | 선택한 **일정**에 따라 확인을 실행합니다. 기본적으로 꺼져 있으며, 저장하면 cron 항목이 추가되거나 제거됩니다.                                                                                                                                                                                                                                                                                    |
| <Terminology title="주소로 현재 접두사를 알려 주는 인터페이스" to="/docs/reference/terminology#interfaces-and-detection">모니터링할 인터페이스</Terminology>   | 필수입니다. <Terminology title="2000::/3 안의 공인 IPv6 주소로, 유일하게 쓰이는 종류" to="/docs/reference/terminology#addresses-and-prefixes">글로벌 주소</Terminology>가 <Terminology title="ISP가 나눠 주는 IPv6 네트워크로, 바뀔 수 있음" to="/docs/reference/terminology#addresses-and-prefixes">위임된 접두사</Terminology>를 담고 있는 인터페이스마다 한 행씩 있습니다. **추가**로 행을 추가하며, 각 인터페이스는 한 번만 나타날 수 있습니다. |
| <Terminology title="ISP 접두사의 크기(예: /56)로, 직접 설정함" to="/docs/reference/terminology#addresses-and-prefixes">위임된 접두사 길이</Terminology> | 각 행에서 필수입니다. `/48`부터 `/64`까지이며, 기본으로 `/56`이 선택되어 있습니다.                                                                                                                                                                                                                                                                                                |
| 일정                                                                                                                                 | 15분마다, 매시간, 6시간마다, 매일 자정 중 하나입니다. 기본값은 매시간입니다.                                                                                                                                                                                                                                                                                                        |

## 필드 선택 \{#field-selection}

설정 탭의 **일정** 아래에는 `필드 탭에서 접두사와 함께 변경할 구성 필드를 선택하십시오.`가 표시됩니다. <Terminology title="한 종류의 설정 전체를 켜고 끄는 스위치 하나" to="/docs/reference/terminology#fields-and-change-plans">필드 그룹</Terminology>과 개별 필드는 **필드** 탭에서 선택하며 이 설정과 별도로 저장되므로, 설정 탭을 저장해도 바뀌지 않습니다. 각 그룹과 그 기본값은 [필드](/docs/configure/configuration-scopes)에서 설명합니다.

## 알림 \{#notifications}

| 필드                                                                                                                      | 설명                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|-------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="주소가 업데이트된 뒤 보내는 알림" to="/docs/reference/terminology#notifications-and-logs">변경 알림 보내기</Terminology> | 기본으로 선택되어 있습니다. 각 <Terminology title="접두사가 바뀌었고 승인된 필드가 모두 업데이트됨" to="/docs/reference/terminology#run-outcomes">성공</Terminology> 후에 <Terminology title="주소가 업데이트된 뒤 보내는 알림" to="/docs/reference/terminology#notifications-and-logs">변경 알림</Terminology>을 보내며, <Terminology title="접두사가 바뀌었지만 이전 접두사를 쓰는 승인된 필드가 없음" to="/docs/reference/terminology#run-outcomes">경고</Terminology> 및 <Terminology title="확인 또는 안전 단계에서 실행이 멈춤" to="/docs/reference/terminology#run-outcomes">실패</Terminology> 알림은 이 설정과 관계없이 표시됩니다. |

## 패키지 업데이트 \{#package-updates}

| 필드 | 설명 |
|-|-|
| 업데이트 확인 | 매일, 매주, 매월 또는 사용 안 함입니다. 기본값은 매주입니다. 확인은 무작위로 정해졌지만 고정된 시각에 실행됩니다. 확인 내용은 [업데이트](/docs/reference/updates)에서 설명합니다. |
| 원격 알림 | 기본으로 꺼져 있습니다. 새 버전 알림을 이메일, Telegram, Pushover 등 pfSense에 구성된 원격 알림 채널로도 보냅니다. |

## 유효성 검사 메시지 \{#validation-messages}

| 메시지                                                       | 원인                                            |
|-----------------------------------------------------------|-----------------------------------------------|
| `모니터링할 구성된 pfSense 인터페이스를 선택하십시오.`                        | 행이 없거나, 어떤 행의 인터페이스가 구성된 pfSense 인터페이스가 아닙니다. |
| `각 인터페이스는 한 번만 나열할 수 있습니다. <interface>에 대한 추가 행을 제거하십시오.` | 두 **모니터링할 인터페이스** 행이 같은 인터페이스를 지정합니다.         |
| `위임된 접두사 길이는 48에서 64 사이여야 합니다.`                           | 길이가 허용 범위를 벗어났습니다.                            |
| `지원되는 패키지 일정을 선택하십시오.`                                    | 일정이 네 가지 옵션 중 하나가 아닙니다.                       |
| `업데이트 확인 주기로 매일, 매주, 매월 또는 사용 안 함을 선택하십시오.`               | **업데이트 확인**이 네 가지 옵션 중 하나가 아닙니다.              |

양식을 저장한 뒤 설정이 바뀌었을 수 있으므로 각 실행은 저장된 설정을 다시 검사합니다. 실행이 보고할 수 있는 메시지는 [문제 해결](/docs/operate/troubleshooting#run-failed)에 나와 있습니다.
