각 <Terminology title="필드 탭에서 스위치 하나로 켜고 끄는 필드 묶음" to="/docs/reference/terminology#field-group">필드 그룹</Terminology>이 다시 쓸 수 있는 정확한 pfSense 구성 경로와 각 경로가 다시 로드하는 서비스를 확인합니다.

## 필드 매트릭스 \{#field-matrix}

경로는 `config_get_path()`와 `config_set_path()`에 쓰는 pfSense의 슬래시 구분 구문을 따릅니다. 아래 경로에서 `<index>`는 목록 위치를, `<interface>`는 `lan` 같은 인터페이스 키를, `<boundary>`는 `from` 또는 `to`를, `<side>`는 `source` 또는 `destination`을, `<section>`은 다른 패키지의 설정 키를 나타냅니다.

| <Terminology title="필드 탭에서 스위치 하나로 켜고 끄는 필드 묶음" to="/docs/reference/terminology#field-group">그룹</Terminology>         | 경로                                                                               | 선택 조건                                                                  | 서비스                     |
|-----------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------|------------------------------------------------------------------------|-------------------------|
| 별칭                                                                                                                    | `aliases/alias/<index>/address`                                                  | `type`이 `host` 또는 `network`                                            | `filter`                |
| 정적 인터페이스                                                                                                              | `interfaces/<interface>/ipaddrv6`                                                | 값에 `:` 문자가 포함됨                                                         | `interfaces`            |
| <Terminology title="CARP나 IP Alias 같은 추가 인터페이스 주소" to="/docs/reference/terminology#virtual-ip">가상 IP 주소</Terminology> | `virtualip/vip/<index>/subnet`                                                   | `mode`가 `carp` 또는 `ipalias`                                            | `interfaces`            |
| IPsec                                                                                                                 | `ipsec/phase2/<index>/localid/address`                                           | `mode`가 `tunnel6` 또는 `vti`이고 `localid/type`이 `address` 또는 `network`    | `ipsec`                 |
| IPsec                                                                                                                 | `ipsec/phase2/<index>/natlocalid/address`                                        | `mode`가 `tunnel6` 또는 `vti`이고 `natlocalid/type`이 `address` 또는 `network` | `ipsec`                 |
| OpenVPN                                                                                                               | `openvpn/openvpn-server/<index>/tunnel_networkv6`                                | `tunnel_networkv6_type`이 `track6` 이외의 값                                | `openvpn`               |
| OpenVPN                                                                                                               | `openvpn/openvpn-server/<index>/local_networkv6`                                 | 항상                                                                     | `openvpn`               |
| OpenVPN                                                                                                               | `openvpn/openvpn-client/<index>/tunnel_networkv6`                                | 항상                                                                     | `openvpn`               |
| OpenVPN                                                                                                               | `openvpn/openvpn-csc/<index>/tunnel_networkv6`                                   | 항상                                                                     | `openvpn`               |
| OpenVPN                                                                                                               | `openvpn/openvpn-csc/<index>/local_networkv6`                                    | 항상                                                                     | `openvpn`               |
| WireGuard                                                                                                             | `installedpackages/wireguard/tunnels/item/<index>/addresses/row/<index>/address` | 항상                                                                     | `wireguard`             |
| DHCPv6 서버                                                                                                             | `dhcpdv6/<interface>/range/<boundary>`                                           | 항상                                                                     | `dhcpv6`                |
| DHCPv6 서버                                                                                                             | `dhcpdv6/<interface>/prefixrange/<boundary>`                                     | 항상                                                                     | `dhcpv6`                |
| DHCPv6 서버                                                                                                             | `dhcpdv6/<interface>/pool/<index>/range/<boundary>`                              | 항상                                                                     | `dhcpv6`                |
| DHCPv6 서버                                                                                                             | `dhcpdv6/<interface>/pool/<index>/prefixrange/<boundary>`                        | 항상                                                                     | `dhcpv6`                |
| DHCPv6 서버                                                                                                             | `dhcpdv6/<interface>/dnsserver/<index>`                                          | 항상, 각 풀 안에서도                                                           | `dhcpv6`                |
| DHCPv6 서버                                                                                                             | `dhcpdv6/<interface>/ntpserver/<index>`                                          | 항상, 각 풀 안에서도                                                           | `dhcpv6`                |
| DHCPv6 서버                                                                                                             | `dhcpdv6/<interface>/staticmap/<index>/ipaddrv6`                                 | 항상                                                                     | `dhcpv6`                |
| 라우터 알림                                                                                                                | `dhcpdv6/<interface>/radnsserver/<index>`                                        | 항상                                                                     | `router_advertisements` |
| 라우터 알림                                                                                                                | `dhcpdv6/<interface>/subnets/item/<index>`                                       | 항상                                                                     | `router_advertisements` |
| DNS 호스트 재정의                                                                                                           | `unbound/hosts/<index>/ip`                                                       | 항상                                                                     | `dns_resolver`          |
| DNS 호스트 재정의                                                                                                           | `dnsmasq/hosts/<index>/ip`                                                       | 항상                                                                     | `dns_forwarder`         |
| 방화벽 규칙                                                                                                                | `filter/rule/<index>/<side>/address`                                             | 해당 쪽에 `network`나 `any` 대신 주소가 들어 있음                                    | `filter`                |
| NAT 및 NPt                                                                                                             | `nat/rule/<index>/<side>/address`                                                | 항상                                                                     | `filter`                |
| NAT 및 NPt                                                                                                             | `nat/rule/<index>/target`                                                        | 항상                                                                     | `filter`                |
| NAT 및 NPt                                                                                                             | `nat/outbound/rule/<index>/<side>/network`                                       | 항상                                                                     | `filter`                |
| NAT 및 NPt                                                                                                             | `nat/outbound/rule/<index>/target`                                               | 항상                                                                     | `filter`                |
| NAT 및 NPt                                                                                                             | `nat/onetoone/<index>/external`                                                  | 항상                                                                     | `filter`                |
| NAT 및 NPt                                                                                                             | `nat/onetoone/<index>/<side>/address`                                            | 항상                                                                     | `filter`                |
| NAT 및 NPt                                                                                                             | `nat/npt/<index>/<side>/address`                                                 | 접두사를 인터페이스에서 추적하지 않고 직접 입력함                                            | `filter`                |
| 다른 패키지의 설정                                                                                                            | `installedpackages/<section>/...`                                                | 값에 IPv6 주소가 들어 있고 [기타 설정](#other-settings)의 어떤 종류에도 해당하지 않음            | `package:<section>`     |

빈 값은 건너뛰며, 대상 ID나 경로가 중복되면 무엇이든 변경하기 전에 실행이 멈춥니다. 각 대상은 [필드 식별자](#field-identities)에 나온 레코드의 식별자에서 ID를 받으며, 레코드에 식별자가 없으면 목록 위치에서 받습니다. [필드](/docs/configure/configuration-scopes#other-packages-settings)에서 설명하듯이 다른 패키지의 필드는 절대 자동으로 선택되지 않습니다.

## 값 형식 \{#value-formats}

- 아래 세 목록을 제외하면 모든 필드에는 값이 하나만 들어 있습니다.
- 별칭 `address`는 공백으로 구분된 목록입니다.
- 서버와 <Terminology title="서버에 있는 클라이언트별 OpenVPN 설정" to="/docs/reference/terminology#client-specific-override">클라이언트별 재정의</Terminology>의 OpenVPN `local_networkv6`는 쉼표와 공백으로 구분된 목록입니다.
- DNS Resolver 호스트 재정의 `ip`는 쉼표와 공백으로 구분된 목록입니다.
- 다른 패키지의 설정과 기타 설정 그룹에 있는 값은 텍스트입니다. 텍스트 안의 모든 주소를 따로 일치시키고 나머지는 쓰인 그대로 유지합니다.
- Base64로 저장된 값은 디코딩한 뒤 텍스트로 일치시키고, 바뀌면 다시 인코딩합니다.
- 구분 기호는 쓰인 그대로 유지되며, 별칭 이름, IPv4 네트워크, 호스트 이름처럼 IPv6 주소가 아닌 토큰은 그대로 통과합니다.

## 일치 규칙 \{#matching-rules}

- 토큰은 `/0`부터 `/128`까지의 CIDR 접미사로 끝날 수 있으며, 이 접미사는 유지됩니다. 그 밖의 접미사가 붙은 토큰은 변경되지 않습니다.
- 토큰은 그 주소가 이전 <Terminology title="/56처럼 네트워크를 나타내는 앞쪽 비트 수" to="/docs/reference/terminology#prefix-length">접두사 길이</Terminology> 기준으로 이전 접두사에 속할 때만 변경됩니다.
- 새 값은 앞쪽 비트를 현재 <Terminology title="/56처럼 네트워크를 나타내는 앞쪽 비트 수" to="/docs/reference/terminology#prefix-length">접두사 길이</Terminology> 기준으로 현재 <Terminology title="pfSense가 모니터링할 인터페이스에 보고하는 글로벌 주소" to="/docs/reference/terminology#source-address">원본 주소</Terminology>에서 가져오고, 나머지 비트는 모두 토큰에서 가져옵니다. 새 값은 <Terminology title="소문자로 쓴 가장 짧은 표준 주소 표기" to="/docs/reference/terminology#canonical-form">정규 형식</Terminology>으로 기록됩니다.
- <Terminology title="2000::/3 범위의 공인 IPv6 주소" to="/docs/reference/terminology#global-unicast-address">글로벌 유니캐스트 주소</Terminology>가 아닌 토큰은 변경 없이 통과합니다. <Terminology title="다른 인터페이스의 위임된 접두사로 주소를 받는 인터페이스" to="/docs/reference/terminology#tracked-interface">Track Interface</Terminology>로 주소를 받는 인터페이스의 DHCPv6 설정에 들어 있는 `::1000` 형태의 접미사도 여기에 해당합니다.
- 새 값이 이전 값과 같은 필드는 변경으로 집계되지 않습니다.

## 필드 식별자 \{#field-identities}

필드 탭의 각 <Terminology title="그룹 스위치와 반대로 선택하거나 선택 해제한 개별 필드" to="/docs/reference/terminology#field-exception">필드 예외</Terminology>는 목록 위치 대신 항목을 가리키는 식별자로 저장됩니다.

| 항목                | 필드 식별자                                                                                                                            |
|-------------------|-----------------------------------------------------------------------------------------------------------------------------------|
| 별칭                | `alias:<name>`                                                                                                                    |
| 정적 인터페이스          | `interface:<interface>`                                                                                                           |
| 가상 IP             | `virtual-ip:<uniqid or description>`                                                                                              |
| IPsec 2단계         | `ipsec:<uniqid, reqid, or ikeid>:<localid or natlocalid>`                                                                         |
| OpenVPN           | `openvpn-server:<vpnid>:<tunnel or local>`, `openvpn-client:<vpnid>:tunnel` 또는 `openvpn-override:<common name>:<tunnel or local>` |
| WireGuard 터널      | `wireguard:<tunnel name>:addresses`. 모든 주소 행을 함께 다룹니다.                                                                            |
| DHCPv6 서버         | `dhcpv6:<interface>:<field>`. `<field>`는 `range-from`, `dns-servers`, `ntp-servers` 같은 설정 이름입니다.                                  |
| DHCPv6 풀          | `dhcpv6-pool:<interface>:<description>:<field>`                                                                                   |
| DHCPv6 정적 매핑      | `dhcpv6-static-mapping:<interface>:<DUID>`                                                                                        |
| 라우터 알림            | `router-advertisements:<interface>:<dns-servers or subnets>`                                                                      |
| DNS Resolver 호스트  | `dns-resolver-host:<host>:<domain>:<inet, inet6, or inet46>`                                                                      |
| DNS Forwarder 호스트 | `dns-forwarder-host:<host>:<domain>:<inet, inet6, or inet46>`                                                                     |
| 방화벽 규칙            | `firewall-rule:<tracker>:<side>`                                                                                                  |
| 포트 포워드            | `port-forward:<created time>:<source, destination, or target>`                                                                    |
| 아웃바운드 NAT 규칙      | `outbound-nat:<created time>:<source, destination, or target>`                                                                    |
| 1:1 NAT 항목        | `one-to-one-nat:<description>:<external, source, or destination>`                                                                 |
| NPt 항목            | `npt:<description>:<side>`                                                                                                        |
| 다른 패키지의 설정        | `package:<section>:<path>`. 경로의 각 목록 위치는 항목을 고유하게 가리키는 필드에서 가져온 `<field>=<value>`가 되고, 패키지의 단일 설정 레코드에서는 `0`이 됩니다.                |
| 기타 설정             | `other:<path>`. 주소를 담지 않는 필드에서 같은 방식으로 만들며, 예를 들면 `name=<gateway name>`입니다. `system/dnsserver` 같은 단순 목록은 모든 항목에 식별자 하나를 유지합니다.    |

- 식별자의 각 부분은 URL 인코딩되므로 `Web forward` 같은 설명은 `Web%20forward`로 표시됩니다.
- 식별자가 없거나 같은 목록의 다른 레코드와 식별자를 공유하는 레코드에는 확인란이 없으며, 그 필드는 그룹 스위치만 따릅니다.
- [명령줄 및 파일](/docs/reference/command-line-and-files#field-selection)에서 설명하듯이 예외는 설정 탭이 저장할 때마다 교체하는 설정 레코드 옆의 `installedpackages/ipv6prefixupdater/fields`에 저장됩니다.
- 각 실행은 저장된 식별자를 다시 검사하고 형식이 잘못된 식별자는 무시합니다. 선택했지만 현재 어떤 항목에도 없는 필드는 건너뛰고 상태 탭의 **건너뛴 필드** 아래에 나열합니다. 식별자는 매트릭스나 기타 설정 그룹에 있는 필드만 가리킬 수 있습니다.

## 다시 로드 작업 \{#reload-actions}

| 서비스                     | 상태 레이블          | pfSense 호출                                                                       |
|-------------------------|-----------------|----------------------------------------------------------------------------------|
| `interfaces`            | 인터페이스           | `interfaces_configure()` 후 `filter_configure()`                                  |
| `routing`               | 라우팅             | `system_routing_configure()` 및 `setup_gateways_monitor()` 후 `filter_configure()` |
| `filter`                | 방화벽 필터          | `filter_configure()`, `interfaces`가 이미 실행했다면 건너뜀                                 |
| `dhcpv6`                | DHCPv6 서버       | `services_dhcpd_configure('inet6')`, radvd도 다시 시작함                               |
| `router_advertisements` | 라우터 알림          | `services_radvd_configure()`, `dhcpv6` 후에는 건너뜀                                   |
| `dns`                   | DNS 서버          | `system_resolvconf_generate()` 후 DNS Resolver와 DNS Forwarder가 활성화되어 있으면 다시 로드    |
| `dns_resolver`          | DNS 해석기         | `services_unbound_configure(false)`                                              |
| `dns_forwarder`         | DNS 전달자         | `services_dnsmasq_configure(false)`                                              |
| `ipsec`                 | IPsec           | `ipsec_configure()`                                                              |
| `openvpn`               | OpenVPN         | `openvpn_resync_all()`                                                           |
| `wireguard`             | WireGuard       | `wg_resync()`                                                                    |
| `package:<section>`     | **패키지** 아래에 나열됨 | XML `<name>`이 섹션과 일치하는 설치된 패키지에 대한 `sync_package()`                              |

서비스는 이 표의 순서대로 다시 로드되며, 다른 패키지의 설정은 다시 로드와 그 검증이 끝난 뒤 마지막으로 다시 적용됩니다. 다시 로드하기 전에, `system_routing_configure()`는 경로를 추가하고 변경하기만 하므로 실행이 교체한 각 정적 경로 네트워크를 `/sbin/route delete`로 라우팅 테이블에서 제거합니다. Static Routes 페이지의 **Apply Changes**도 같은 동작을 합니다. pfSense 2.7.2에서는 `interfaces_configure()`가 이미 DHCPv6, radvd, 두 DNS 서비스를 다시 시작하므로, 그 뒤에는 이 서비스들의 다시 로드를 건너뜁니다.

DNS Forwarder나 DNS Resolver가 DHCP 정적 매핑을 등록하면 `dhcpv6`는 대신 그 서비스의 다시 로드를 실행하며, 이때 DHCP도 다시 시작됩니다. 이는 DHCPv6 Server 페이지의 **Apply Changes**와 같은 동작입니다.

`sync_package()`는 패키지의 **Save** 버튼처럼 그 패키지의 재동기화 명령을 실행하며, 출력은 버립니다. 설치된 패키지가 소유하지 않은 섹션은 적용하지 않고 보고만 하며, 실패는 해당 패키지에 대해 보고됩니다. 어느 쪽도 저장된 값을 되돌리지 않습니다.

백업 전에 사전 점검 단계가 `/etc/inc/filter.inc`, `/etc/inc/pkg-utils.inc`, `/usr/local/pkg/wireguard/includes/wg.inc` 같은 고정된 파일에서 필요한 함수를 각각 불러오며, 하나라도 없으면 실행을 멈춥니다. `filter_configure()`, `services_unbound_configure()`, `services_dnsmasq_configure()`는 `false`나 0이 아닌 정수를 반환하면 실행을 실패시키고, 다른 호출은 예외를 던질 때만 실행을 실패시킵니다.

## 기타 설정 \{#other-settings}

값에 IPv6 주소가 텍스트나 Base64로 들어 있는 그 밖의 모든 구성 경로는 **기타 설정** 그룹에 속합니다. 이 그룹은 꺼진 상태로 시작하며, 그 안의 값은 선택되어 있거나 그룹이 켜져 있을 때만 바뀝니다. 행에는 다음 종류가 표시됩니다.

- IPsec `remoteid` ID와 1단계 원격 게이트웨이, OpenVPN `remote_networkv6` 네트워크와 클라이언트의 서버 주소.
- 허용 IP와 엔드포인트를 포함한 WireGuard 피어.
- 게이트웨이와 정적 경로.
- 탭에서 값이 숨겨지는 인증서, 키, 암호 및 기타 비밀 값.
- Base64로 저장된 그 밖의 모든 값.
- 설명.
- 다른 패키지의 설정에서 이름이 인증서, 키, 암호, 비밀, 해시 또는 설명을 나타내는 값.

`host` 및 `network` 이외의 별칭 유형, `carp` 및 `ipalias` 이외의 <Terminology title="CARP나 IP Alias 같은 추가 인터페이스 주소" to="/docs/reference/terminology#virtual-ip">가상 IP</Terminology> 모드, 매트릭스 밖의 그 밖의 모든 경로에는 종류 대신 설정 이름이 표시됩니다. 다시 로드는 경로에 따라 정해집니다. `gateways`와 `staticroutes`는 `routing`, `system/dnsserver`는 `dns`, `unbound`와 `dnsmasq`는 각자의 DNS 서비스, `ipsec`, `openvpn`, `filter`, `aliases`, `nat`, `dhcpdv6`, `interfaces`, `virtualip`는 위의 다시 로드를 사용하고, 다른 패키지의 섹션은 다시 적용되며, 설명, 인증서, 그 밖의 모든 경로는 아무것도 다시 로드하지 않습니다.

## 쓰기와 검증 \{#write-and-verification}

- 백업 전에 계획된 모든 경로는 계획된 이전 값을 가지고 있어야 합니다.
- 다음으로 `backup_config()`가 실행되며 `true`를 반환해야 합니다.
- 계획은 `config_set_path()`로 적용되고 `write_config($description, false, true)`로 한 번 저장되며, 이 호출은 두 번째 백업과 관련 없는 동기화를 건너뜁니다.
- 쓰기 후, 그리고 다시 로드 후에 한 번 더, 계획된 모든 경로는 계획된 새 값을 가지고 있어야 합니다.

값이 일치하지 않으면 실행은 `구성 경로 "<path>"이(가) 승인된 계획 밖에서 변경되었습니다.` 메시지와 함께 멈춥니다. [실행 결과](/docs/operate/run-outcomes#failures-after-the-save)에서 설명하듯이 쓰기 후에 실패하면 새 값은 저장된 채로 남습니다.
