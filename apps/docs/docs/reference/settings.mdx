Look up every field on the Settings tab with its default and the values it accepts.

## Prefix Monitoring

The **Settings** tab under **Services → IPv6 Prefix Updater** starts with these fields, and saving the form shows `Settings saved.`

| Field                                                                                                                                                                     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="Automatic checks on a schedule, off until you enable them" to="/docs/reference/terminology#running-checks">Enable Scheduled Updates</Terminology>     | Runs checks on the selected **Schedule**. Off by default, and saving adds or removes the cron entry.                                                                                                                                                                                                                                                                                                                                            |
| <Terminology title="The interface whose address reveals your current prefix" to="/docs/reference/terminology#interfaces-and-detection">Monitored Interfaces</Terminology> | Required. One row per interface whose <Terminology title="A public IPv6 address in 2000::/3, the only kind used" to="/docs/reference/terminology#addresses-and-prefixes">global address</Terminology> carries a <Terminology title="The IPv6 network your ISP hands you, which can change" to="/docs/reference/terminology#addresses-and-prefixes">delegated prefix</Terminology>. **Add** adds a row, and each interface can appear only once. |
| <Terminology title="How big your ISP's prefix is, like /56; you set it" to="/docs/reference/terminology#addresses-and-prefixes">Delegated Prefix Length</Terminology>     | Required in each row. `/48` through `/64`, with `/56` selected by default.                                                                                                                                                                                                                                                                                                                                                                      |
| Schedule                                                                                                                                                                  | Every 15 minutes, Hourly, Every 6 hours, or Daily at midnight. Hourly by default.                                                                                                                                                                                                                                                                                                                                                               |

## Field Selection

Below **Schedule**, the Settings tab shows `Choose which configuration fields change with the prefix on the Fields tab.` The <Terminology title="One switch for a whole kind of setting" to="/docs/reference/terminology#fields-and-change-plans">field groups</Terminology> and single fields are chosen on the **Fields** tab and saved apart from these settings, so saving the Settings tab never changes them. [Fields](/docs/configure/configuration-scopes) describes each group and its default.

## Notifications

| Field                                                                                                                                                                 | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="The alert sent after your addresses were updated" to="/docs/reference/terminology#notifications-and-logs">Send Change Notifications</Terminology> | Selected by default. Sends a <Terminology title="The alert sent after your addresses were updated" to="/docs/reference/terminology#notifications-and-logs">change notification</Terminology> after each <Terminology title="Prefix changed and every approved field was updated" to="/docs/reference/terminology#run-outcomes">Success</Terminology>, while <Terminology title="Prefix changed, but no approved field used the old one" to="/docs/reference/terminology#run-outcomes">Warning</Terminology> and <Terminology title="The run stopped at a check or safety stage" to="/docs/reference/terminology#run-outcomes">Failure</Terminology> notices appear either way. |

## Package Updates

| Field                | Description                                                                                                                                                 |
|----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Update Checks        | Daily, Weekly, Monthly, or Never. Weekly by default. The check runs at a stable randomized time. [Updates](/docs/reference/updates) describes what it does. |
| Remote Notifications | Off by default. Also sends each new-version notice through pfSense's configured remote notification channels, such as email, Telegram, or Pushover.         |

## Validation Messages

| Message                                                                         | Cause                                                                     |
|---------------------------------------------------------------------------------|---------------------------------------------------------------------------|
| `Select a configured pfSense interface to monitor.`                             | No row exists, or a row's interface isn't a configured pfSense interface. |
| `Each interface can be listed only once. Remove the extra row for <interface>.` | Two **Monitored Interfaces** rows name the same interface.                |
| `The delegated prefix length must be from 48 through 64.`                       | The length is outside the accepted range.                                 |
| `Select a supported package schedule.`                                          | The schedule isn't one of the four options.                               |
| `Select Daily, Weekly, Monthly, or Never for update checks.`                    | **Update Checks** isn't one of the four options.                          |

Each run checks the saved settings again, because they could have changed after the form was saved. [Troubleshooting](/docs/operate/troubleshooting#run-failed) lists the messages a run can report.
