Look up every field on the Settings tab with its default and the values it accepts.

## Prefix Monitoring

The **Settings** tab under **Services → IPv6 Prefix Updater** starts with these fields, and saving the form shows `Settings saved.`

| Field                                                                                                                                                                 | Description                                                                                                                                                                                                                                                                                                                                                                                                    |
|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="automatic checks run from a pfSense-managed cron entry" to="/docs/reference/terminology#scheduled-updates">Enable Scheduled Updates</Terminology> | Runs checks on the selected **Schedule**. Off by default, and saving adds or removes the cron entry.                                                                                                                                                                                                                                                                                                           |
| <Terminology title="interface whose address reveals the current prefix" to="/docs/reference/terminology#monitored-interface">Monitored Interfaces</Terminology>       | Required. One row per interface whose <Terminology title="public IPv6 address inside 2000::/3" to="/docs/reference/terminology#global-unicast-address">global address</Terminology> carries a <Terminology title="IPv6 network your ISP routes to the firewall" to="/docs/reference/terminology#delegated-prefix">delegated prefix</Terminology>. **Add** adds a row, and each interface can appear only once. |
| <Terminology title="setting for the ISP prefix size, /48 to /64" to="/docs/reference/terminology#delegated-prefix-length">Delegated Prefix Length</Terminology>       | Required in each row. `/48` through `/64`, with `/56` selected by default.                                                                                                                                                                                                                                                                                                                                     |
| Schedule                                                                                                                                                              | Every 15 minutes, Hourly, Every 6 hours, or Daily at midnight. Hourly by default.                                                                                                                                                                                                                                                                                                                              |

## Field Selection

Below **Schedule**, the Settings tab shows `Choose which configuration fields change with the prefix on the Fields tab.` The <Terminology title="group of fields with one switch on the Fields tab" to="/docs/reference/terminology#field-group">field groups</Terminology> and single fields are chosen on the **Fields** tab and saved apart from these settings, so saving the Settings tab never changes them. [Fields](/docs/configure/configuration-scopes) describes each group and its default.

## Notifications

| Field                                                                                                                                                           | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|-----------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <Terminology title="alert sent after a verified successful update" to="/docs/reference/terminology#change-notification">Send Change Notifications</Terminology> | Selected by default. Sends a <Terminology title="alert sent after a verified successful update" to="/docs/reference/terminology#change-notification">change notification</Terminology> after each <Terminology title="outcome: fields updated, saved, reloaded, and verified" to="/docs/reference/terminology#success">Success</Terminology>, while <Terminology title="outcome: prefix changed, but no approved field matched" to="/docs/reference/terminology#warning">Warning</Terminology> and <Terminology title="outcome: a check or safety stage stopped the run" to="/docs/reference/terminology#failure">Failure</Terminology> notices appear either way. |

## Validation Messages

| Message                                                                         | Cause                                                                     |
|---------------------------------------------------------------------------------|---------------------------------------------------------------------------|
| `Select a configured pfSense interface to monitor.`                             | No row exists, or a row's interface isn't a configured pfSense interface. |
| `Each interface can be listed only once. Remove the extra row for <interface>.` | Two **Monitored Interfaces** rows name the same interface.                |
| `The delegated prefix length must be from 48 through 64.`                       | The length is outside the accepted range.                                 |
| `Select a supported package schedule.`                                          | The schedule isn't one of the four options.                               |

Each run checks the saved settings again, because they could have changed after the form was saved. [Troubleshooting](/docs/operate/troubleshooting#run-failed) lists the messages a run can report.
